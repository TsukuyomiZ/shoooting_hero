# Shooting Hero（彈彈堂風格 PVE 共鬥最多 4 人，另有勝者為王 3v3 對戰）

純 HTML5 Canvas + vanilla JS 客戶端，Node + `ws` 伺服器。同一份遊戲邏輯（`shared/`）在伺服器與瀏覽器上跑，
伺服器是唯一的裁判，瀏覽器只送輸入、收結果播動畫。

## 執行

```bash
npm install
npm start
```

然後開 <http://localhost:8123>。伺服器啟動時會印出區網 IP，朋友在同一個網路下用那個網址就能加入。
放到公網時請放在有 TLS 的反向代理後面（wss），或用 Render / Fly.io / Railway 之類的平台。

> 現在用的是 ES modules，直接雙擊 `index.html` 會被瀏覽器擋住，一定要透過伺服器開。

### 同事連不進來？

1. 確認同事用的是伺服器印出的「區網」網址（例如 `http://172.23.192.67:8123`），而且跟你在同一個網路。
2. 多半是 Windows 防火牆擋了 Node.js 的連入（第一次開埠時的防火牆詢問按了取消，就會留下「封鎖」規則）。
   以**系統管理員**開 PowerShell 執行：

   ```powershell
   Set-NetFirewallRule -DisplayName "Node.js JavaScript Runtime" -Action Allow -Profile Domain,Private
   ```

   或走 GUI：開始 → 搜尋「允許應用程式通過 Windows 防火牆」→ 變更設定 → 勾選 Node.js JavaScript Runtime 的「網域」與「私人」。
   改完不用重啟伺服器。
3. 沒有管理員權限、或同事不在同一個網路：用免費的 Cloudflare 通道把伺服器暴露成公開網址（支援 WebSocket、自帶 TLS）：

   ```powershell
   winget install Cloudflare.cloudflared
   cloudflared tunnel --url http://localhost:8123
   ```

   把它印出的 `https://xxxx.trycloudflare.com` 網址給同事即可。

## 大廳

- **模式**（選單最上面，記在瀏覽器裡）：**冒險**（PVE 共鬥，最多 4 人）/ **主題副本**（也是冒險，一整場同一種地形，見「主題副本」；有開放中的主題才出現）/ **勝者為王 3v3**（對戰，見「勝者為王」）。單人練習、建立房間都照這裡選的；
  選勝者為王時沒有難度可選，單人練習 = 自己加 5 個電腦玩家（自己在藍隊）。大廳列表上勝者為王的房間另外標「勝者為王」、主題副本的房間標主題的名字（例如「莫利亞森林」）。
- **難度**（單人練習、建立房間都照這裡選的；記在瀏覽器裡）：**一般** / **菁英之路**（見「肉鴿流程」）。底下一行照那個難度實際的設定寫出哪幾關是菁英關、敵人傷害打不打折。
  房間裡、大廳列表上會標出難度（列表只標不是一般的）；一般以外的難度第 1 關開場的橫幅多一行難度說明，結算畫面也會寫。
- **單人練習**：不連線，裁判直接在瀏覽器裡跑，流程跟多人完全一樣。
- 打開頁面就會連上伺服器，選單下方的 **大廳 · 公開房間** 即時列出所有公開房間（房號、房主、人數，點一列就加入；
  遊戲中 / 已滿的灰掉不能點；冒險打完的房間馬上從列表消失）。連不上伺服器時列表顯示「重試」，單人練習照樣能玩。
- **建立房間** → 拿到 4 碼房號；旁邊勾 **私人房間** 就不會出現在大廳列表，只能輸入房號進場。
  房主在房間裡可以隨時切換公開 / 私人（其他人只看得到標籤）。
- **輸入房號加入**：公開、私人房間都能用房號進場。
- 所有人按「準備」後，房主按「開始遊戲」。遊戲開始後不能再加入。
- 偵測到瀏覽器好像沒開 **硬體加速**（只拿得到軟體繪圖的 WebGL，見 `client/gpu-check.js`）時，標題下方會出現提醒：這個瀏覽器怎麼打開，
  加上可以複製的設定頁網址（網頁不能直接連到 `chrome://` 之類的網址）。按「知道了」這個分頁就不再出現。
  Safari / iPhone / iPad / 手機沒有這個開關，不偵測；Firefox 關掉加速時 WebGL 照樣用顯示卡，多半偵測不到。
- 標題旁是版本階段（目前 **BETA**）。大廳下方是 **版本履歷**：直接條列每一版改了什麼（新增 / 調整 / 修正，最新的在最上面、預設展開，
  舊版本點一下展開），右邊的「收合」按鈕把整塊收起來（記在瀏覽器裡；出了新版本會自動再展開，最新那版標 `NEW`）。

## 版本

版本號設定與版本履歷都在 `shared/core/version.js`：

- `VERSION`：`channel` 是階段（`'ALPHA'` / `'BETA'` / `''` = 正式版），`number` 是版本號；畫面上顯示成 `BETA v1.4`。
- `CHANGELOG`：版本履歷，新的在最上面；每一筆 `{ version, channel, date, title, new: [...], change: [...], fix: [...] }`
  （新增 / 調整 / 修正，沒有的種類省略）。
- **改版時**：改 `VERSION.number`（要換階段就改 `channel`），在 `CHANGELOG` 最上面加一筆同版本號的紀錄，
  `package.json` 的 `version` 跟著改（`1.2` BETA → `1.2.0-beta`）；還沒改版前的改動就加在最上面那一筆裡。
  `npm test` 的 `test/version.js` 會檢查三個地方對得上、版本與日期由新到舊。
- 伺服器啟動（`server.start`）與單人練習開始（`solo.start`）的紀錄會帶 `version`，查 LOG 時知道是哪一版玩的。

## 操作

| 按鍵 / 滑鼠 | 動作 |
| --- | --- |
| `A` / `D` | 左右移動（每秒消耗 45 體力，空中也能微調） |
| `空白鍵` | 跳躍（消耗 30 體力，可以跳過缺口）；有雲霧之瓶時在空中可以再跳一次 |
| `W` / `S` | 爬藤蔓（叢林巨蟒）：按住時身體碰到藤蔓就抓住，往上 / 往下爬（跟走路一樣每秒消耗 45 體力）；自己的回合掛著不動也每秒消耗 20 體力，體力用完就鬆手掉下去；按著 W / S 就是抓緊（邊走邊跳過去也抓得住），沒按時 `A` / `D` 放手；`空白鍵` 從藤蔓上跳開（同時按 `A` / `D` 就往那邊跳） |
| 按住滑鼠左鍵 | 開始瞄準：滑鼠方向 = 角度，拖曳距離 = 力量（10~100）。**跳起來之後瞄準會進入慢動作**（要真的按了跳；走下坡、走下台階、被打飛的離地都不算）：整個畫面慢 80%（只剩 20% 的速度），每秒（真實時間）消耗 50 體力，體力歸零、落地或抓到藤蔓就解除；回合倒數照真實時間走 |
| 放開左鍵 | 發射並結束本回合（空中也能開火：從當下的位置出手，之後照原本的速度落下）；飛鏢一回合可以射三次，射完三次（或時間到）才結束 |
| `1` / `2` / `3` | 切換武器欄第 1 / 2 / 3 格的武器（也可點畫面上方按鈕） |
| `R` | 結束後回到大廳 |
| `M` | 背景音樂靜音 / 恢復成原本的音量 |
| 右上角喇叭按鈕 | 音量設定：音樂、音效各一條滑桿（0~100，會記住，下次進來照舊）；`Esc` 或點面板外面關閉 |
| 右下角貼圖按鈕 | 丟反應貼圖：像彈幕一樣從畫面右邊飄到左邊，所有人都看得到；只走頂部 HUD 正下方的三排（不擋戰場），同時好幾張會分到三排一起飄、三排都滿了才排隊（誰丟的會標名字；自己丟的有外框）。任何時候都能按，選牌時也行；每人 3 秒內最多 4 張 |
| `Enter` / 貼圖列的 💬 | 聊天：打開左下角的輸入框（上面列出最近 6 則），`Enter` 送出、`Esc` 取消、點回戰場收起來（打到一半的字留著）。送出的字跟貼圖共用那三排彈幕軌道，所有人都看得到；一則最多 30 個字，每人 4 秒內最多 3 則。打字時角色不會動 |

### 新增反應貼圖

圖檔放 `assets/stickers/`（建議正方形、透明背景，32~128px），然後在 `shared/social/stickers.js` 的 `STICKERS` 加一行
`{ id: '英數字代號', label: '滑鼠移上去的說明', src: 'assets/stickers/檔名' }`，重啟伺服器、重新整理頁面即可。洗版上限也在同一個檔案（`STICKER_LIMIT`）。

### 背景音樂與音效

小關放 `assets/music/canyon-echoes.mp3`，狂熱生效（4 人第 8 輪、2 ~ 3 人第 9 輪、1 人第 10 輪起）的那一刻交叉淡入 `canyon-fever.mp3`；
洞穴地圖（岩穴、地心探險）放 `sneaky-desert-adventure.mp3`，狂熱生效後換洞穴的狂熱版 `sneaky-desert-fever.mp3`；巨蠍巢穴放 `sneaky-desert-scorpion.mp3`（三首都由地圖畫面的 `musicTrack` 指定，狂熱版也是）。
古樹之庭放 `guardian-of-the-canopy.mp3`（原曲；`client/ambience.js` 有合成樹葉聲可以疊上去，在 `TRACKS.tree` 加 `leaves: 1` 就會開）；叢林巨蟒放 `savage-jungle-menace.mp3`，進關時前一首很快收掉，先播一聲合成的蛇哈氣（`sfx.js` 的 `snakeHiss`，吃「音樂」音量），音樂接著淡入（時間和音量在 `music.js` 的 `HISS`）。
整首循環播放（曲尾本身有淡出，直接接回開頭）；切到別的分頁、縮小視窗時音樂和音效照樣播（同時開好幾個分頁測多人時，把其他分頁的音量拉到 0，免得好幾份聲音疊在一起）。
換曲、調曲子的相對音量、樹葉聲大小（`leaves`）改 `client/music.js` 最上面的 `TRACKS`；風多久一陣、葉子 / 風聲 / 脆響各多大聲在 `ambience.js` 最上面；哪一關放哪首在 `GameView.musicTrack()`（小關、菁英關放山谷曲 / 狂熱版；Boss 關問地圖畫面的 `musicTrack`，見 `client/map-views/`）。

音效全部用 Web Audio 即時合成（沒有音檔），在 `client/sfx.js` 的 `SOUNDS`：腳步、跳躍、大砲（等離子飛彈、迴力鏢也用這個）、飛鏢（破風聲、插進地面的「咚」）、高壓水炮（噴水聲、射程到了散掉的嘶聲）、西洋刺劍（刺出去的「唰」，刺中也是「咚」）、
狙擊槍（後面帶兩聲山谷回聲）、爆炸（大坑 / 小坑兩種）、砲彈落水、角色落水、被打中。聲音會照發生的位置分左右聲道。
輪到自己的回合（單人、多人都一樣）會響「叮、叮、叮——」提示音（`yourTurn`，不分左右聲道）：平常跟「你的回合」橫幅一起響；
分頁在背景時畫面會落後，收到回合訊息就先響（`GameView.cueTurn`）。AI 代打、重連回到自己的回合不響。
音量設定（音樂 / 音效兩條匯流排、存 localStorage）在 `client/audio.js`，面板在 `client/settings-ui.js`。
這些都只改前端，不用重啟伺服器，重新整理頁面就好。

## 規則

- 回合順序：玩家 1 → 2 → 3 → 4 → 敵人 A → 敵人 B，每回合 30 秒，回合開始體力回滿。
- 敵人血量隨人數放大：每多一位玩家 +50%。
- 敵人（含古樹、樹妖、巨蟒、狙擊手、砲兵、蜜蜂）造成的傷害 = 武器傷害 × 敵人傷害倍率（再吃狂熱）：
  **第一輪（第 1 ~ 5 關）×0.7**（`ENEMY.damageMult`），**第二輪（第 6 關起）×1**，不再抑制（`ENEMY.damageMultLate`、`lateFromStage`）。
  難度選**菁英之路**的話整場都是 ×1（小怪、菁英怪、Boss 都不打折）。
- 隊友誤傷（含打到自己）傷害 ×0.6。
- **狂熱**：避免雙方血量太多、一關打太久。一般小關每過 N 輪（左上的「第 N 輪」），所有角色（玩家與敵人）造成的傷害 +50%，
  會疊加，每關重新從 0 算。誤傷、燃燒也吃這個加成，回血不受影響。N 照這一關的玩家人數（人越多一輪越久，就越早狂熱）：

  | 人數 | 幾輪一層 | 第一層（+50%） | 第二層（+100%） |
  |---|---|---|---|
  | 4 人 | 7 輪 | 第 8 輪起 | 第 15 輪起 |
  | 2 ~ 3 人 | 8 輪 | 第 9 輪起 | 第 17 輪起 |
  | 1 人 | 9 輪 | 第 10 輪起 | 第 19 輪起 |

  **Boss 關不套用**（Boss 關有自己的機制）；菁英關照小關一樣套用。疊上新的一層時橫幅會提示，生效中左上會有「狂熱」標籤。
  參數在 `CONFIG.FEVER`（`everyRounds: { 人數: 輪數 }`，填一個數字 = 不分人數、`0` = 關掉；`inBoss: true` = Boss 關也套用）。
  有人帶著**狂歡派對**（`feverStartRound` 2）時，這一關的第一層提早到第 2 輪，之後照樣每過 N 輪再疊一層（4 人：第 2、9、16 輪起…；
  好幾個人帶的話照最早的，不會比原本還晚；Boss 關照樣沒有）。開場時從大家的牌算好（`Match` 問效果的 `feverFrom`，交給關卡規則），
  客戶端用同一份 carry 建 `Match`，兩邊的層數一樣。狂熱疊上新的一層時畫面上會飄過一群氣球（效果的 `feverFx`，只是演出：牌的說明、版本履歷都不寫）。
- 上面的敵人血量 / 傷害倍率、狂熱，加上哪幾關是王關（`RUN.bossStages`）與王關的血量成長（`RUN.bossHpPerStage`），合起來是**關卡規則**（見 GLOSSARY.md）：
  數值照樣在 `shared/core/config.js`，算法全在 `shared/game/stage-rules.js` 一個檔案。一關開場就算好（`match.rules`）；第幾輪記在 `match.round`，
  狂熱層數 `match.fever` 由它推出，伺服器、畫面（HUD、橫幅、換狂熱曲、狀態列）都讀同一個。
- 有人斷線：輪到他時由 AI 代打（用他武器欄裡的武器）；重新整理頁面會用 token 自動回到原本的遊戲。
- 地形可破壞。**落水**：敵人（含樹妖）直接淹死。玩家扣最大血量的 30%（不吃狂熱、減傷、神佑之石），扣完沒血才會淹死；
  撐得住就馬上回到最後站穩的地方，那裡被炸掉了就找最近站得住的地面。自己的回合掉下去回合**不會結束**：
  還有體力就能接著走、照常開火、計時照走（方向鍵要放開重按才會再走，免得一回到崖邊又走下去）；淹死才結束回合。
  打進水裡淹死一樣算擊殺。參數在 `CONFIG.WATER`（`enemiesDrown: false` = 敵人也照玩家的規則）。
- **風向**（共用機制，2026-10-20 跟著菁英關「天狗」做的；規則在 `shared/physics/wind.js`）：關卡寫 `wind: true`（或 `{ max }`）才有風，目前只有天狗。
  **每個回合開始**（玩家、敵人的回合都算）重抽一次，-10 ~ +10 級（負的往左吹、正的往右吹、0 = 無風；`CONFIG.WIND.max`），畫面上方武器選擇的下面顯示風向箭頭與級數。
  這一回合射出去的**拋物線飛行物**（有重力的：大砲、等離子、飛鏢、敵人的拋射招式…）多一個水平加速度 = 級數 × `WIND.accel`（9 px/s²；
  大砲飛 2 秒、10 級風大約偏 180 px）；直線的（狙擊槍、劍氣、羽毛、直直落下的無差別轟炸…）不吃風，武器寫 `windFactor` 可以改（獨眼巨人一定砸中的巨石是 0：軌跡是先解好的）。
  瞄準的預覽點、全知之眼的整條拋物線、AI 的試射都照同一陣風算（預覽只畫前面一小段，後半段還是要自己預測）。
  伺服器抽風（`Match.rollWind`，跟著 `turn` 訊息與快照給客戶端）；飛行物建出來時就把風的加速度放在身上（`p.wind`），`shot.projectiles` 帶著，客戶端重播照它飛，兩邊一樣。
- 全部敵人倒下即勝利，全隊倒下即失敗。

### 武器

每個角色有一個**武器欄，最多 3 把**（`config.EQUIP.maxWeapons`）。開局是大砲 + 狙擊槍，
選牌時可能抽到武器牌：欄位沒滿就直接裝上；滿了就要先選一把丟掉（新武器放進被丟掉的那一格），也可以取消改選別張。
數值（傷害、半徑、重力、擊退）都在 `config.WEAPONS`。

- **大砲**：拋物線、會炸坑並擊退，瞄準時只顯示前 4 個點（有全知之眼時拋射武器都畫完整條拋物線與落點準星）。有蹦蹦炸彈時砲彈碰到地形先彈一次（跟哈哈子彈一樣照地表反射、不減速，彈的那一下不爆炸），下一次碰到東西才爆炸。
- **狙擊槍**：無重力直線飛行，瞄準時顯示完整路線（有哈哈子彈會畫出彈射後的路線，有高倍率望遠鏡會標出穿透點）。
- **迴力鏢**（武器牌）：拋物線，飛到最長路徑（`rangeMin` + 力量 × `rangePerPower`，力量 100 = 600px）才沿原路飛回角色手上；
  中途先撞到地形、落水或飛出場外就提早折返。去程、回程都會穿過路上的敵人並打到（同一個敵人去回各一次），不會打到隊友與自己；不爆炸、不挖地。
- **等離子飛彈**（武器牌）：同一條彈道隔 10 幀連射兩發（2026-10-14 從三發改成兩發），每發傷害 30、都會爆炸挖坑。
- **飛鏢**（武器牌，綠）：速度固定（跟力量無關）、有一點重力的直線，傷害 10、不爆炸。**一回合可以分開射三次**（`shotsPerTurn`）：
  每射一支回合不結束，可以再移動、瞄準（體力照用、不回滿）；飛行與結算時計時暫停，回來接著倒數；射出第一支之後這回合只能用飛鏢。
  每一支都算一次射擊（磨刀霍霍 / 越戰越強的層數、命中率、燃燒子彈都照一支一支算）。斷線代打只會再射一支（只能用飛鏢）。
- **高壓水炮**（武器牌，白）：直線，**射程 300px**（飛過 300px 還沒打到東西就散掉，沒有傷害），傷害 40、範圍 40、擊退 200，不挖地形。
  開炮的同時自己被往反方向推（後座力 `recoil` 100，跟被擊退同一套：抓著藤蔓會被打下來，推進水裡一樣落水）。
- **西洋刺劍**（武器牌，綠）：往前方直直刺出一劍（速度固定、跟力量無關），**攻擊距離很短（160px）**，刺出 160px 還沒碰到東西就收回（沒有傷害）。
  傷害 30、不爆炸、不挖地、擊退 60；穿過隊友（自己人刺不到），**刺中的敵人附加 10 層流血**（`bleed`，流血規則見下面）。瞄準線停在射程的地方。

### 裝備的特殊狀態

- **燃燒**：在自己的回合結束時，每層扣最大血量 0.1%；在自己的回合移動可以甩掉層數（每 10px 一層，每回合最多 10 層；蝙蝠飄、獨眼巨人走的距離也算）。
- **著火**（共同設定，2026-10-22，`shared/physics/fire.js`）：**任何一方**的飛行物穿過場上的**火源**就著火，之後打中的**對方**附加那個火源的燃燒層數（直擊、爆炸波及都算；
  跟燃燒子彈等牌的層數相加；隊友不會燒到、免疫異常狀態的不上）。一直燒到這顆結束（彈射、穿透、迴力鏢回程都還燒著）；一次穿過好幾個取最大的火，
  已經著火的只有穿過更大的火才換成那個大小（不疊加）。穿過火源跟打中目標在同一幀（例如狙擊槍很快）也算：結算傷害之前就著火。
  帶不了火的：武器寫 `noFire` 的（高壓水炮、沿地面跑的震波、震盪獅吼）、用身體撞過去的招式（`bodyHit`）、半路才出現的飛行物（掉下來的鐘乳石、吊燈）。
  火源 = 一段線段往外 `r` px（膠囊形）加上燃燒層數 `burn`，由地圖機制的 `fireSources(match, owner)` 給（哪些火源對誰算數也由它決定）；
  目前只有洞穴的火把（見「小關：岩穴」）。之後新的火把、或不是火把的東西要讓子彈著火，只要地圖機制回傳它的火源，著火的規則、同步、畫面都不用改。
  著火的那一下「呼」一聲竄出一團火，飛行物拖著火舌、噴火星（地圖畫面自己畫的招式也一樣），在洞穴的暗處也照亮周圍一小圈。
- **流血**（`config.BLEED`，會流血的攻擊命中時附加層數：武器的 `bleed`，例如大樹守衛的橫劈、獨眼巨人的巨石投擲各 5 層，西洋刺劍 10 層）：帶著流血**自己移動**時，每移動 1px、每層扣最大血量 0.01%（`pctPerPx`，照現在的上限算，
  不足 1 點的先存著；5 層、150 血走 100px = 7.5 血）。算的是走路的水平距離（跳在空中按方向也算）、爬藤蔓的上下距離、蝙蝠飄 / 獨眼巨人走的直線距離；
  被擊退、跳起來 / 掉下去的上下、落水重生都不算。不吃減傷、狂熱、無敵（無敵擋的是上流血的那一下；誤傷、連結分到的那份不會上流血），**會扣到倒下**。
  層數一直疊（沒有上限），**自己的回合結束時止血**（層數全部清掉）。流血扣的血算上流血的人造成的傷害，扣到倒下也算他的擊殺。
  自己的回合走路扣的血由自己的畫面先扣、跟位置一起回報（伺服器只收比現在少的）；走到一半倒下，這回合就結束（敵人、代打走到一半倒下就不開火、不出招）。
  血條右邊的紅色血滴 = 流血層數（跟燃燒、中毒的標記排成一排；站在畫面最右邊、右邊放不下時整排改放到血條左邊），邊走邊飄「-N」，止血時飄「止血」。
  選牌畫面出現會流血的武器牌時，下面會補一行流血的說明。
- **無敵**（神佑之石）：擋下下一次傷害（也不會被擊退），不會疊加。
- **額外回合**（時間扭曲）：普通回合結束後馬上再輪到自己一次（完整回合：體力回滿、會觸發回合開始 / 結束的裝備效果，不算新的一輪）；
  之後要再過 3 個普通回合才會再給，額外回合本身不能再接額外回合。
- **無差別轟炸**：持有者的回合開始時先播轟炸，播完才開始計時；持有者左右 60px 內不落彈，其他地方（包括隊友）都會被炸。飛彈不炸壞地形（`noCarve`，範圍傷害照舊）。
  同一次轟炸每個目標最多被炸到 3 次（`config.WEAPONS.bombard.maxHits`；每一筆傷害算一次，直擊、波及、被擋下、地圖機制處理的都算，攜手之伴分到的不算）：
  打到第 3 次之後，後面的飛彈穿過他、爆炸也炸不到他，大體積的怪物（例如叢林巨蟒）不會被整排飛彈炸滿。
  好幾個部位的怪物（`Entity.body`：洞穴巨蠍的背甲 / 巨鉗 / 毒針、古樹之眼 / 之口）整隻合起來算 3 次；一發同時波及好幾個部位會超過的話，先算直擊的、再算離爆炸點近的。
  轟炸打下來的鐘乳石是它自己砸的，不算轟炸。
  飛彈的傷害跟持有者自己的其他攻擊一樣吃他的加成（武器傷害、對首領、擊退、吸血；只限大砲 / 狙擊槍的加成不算）；轟炸不吃燃燒子彈等牌的燃燒、不算射擊
  （飛彈在洞穴裡穿過火把一樣會著火、打中的對方附加火把的燃燒：那是**著火**的共同設定，不是牌的燃燒）。
  轟炸之後冷卻 3 個自己的回合（`config.EQUIP.bombard.cooldown`）：轟炸 → 跳過 3 個回合 → 再轟炸；時間扭曲的額外回合也算一個回合（會轟炸、也會減冷卻）。
  冷卻每關重算（每關第一個自己的回合一定轟炸），狀態列顯示「無差別轟炸 冷卻 N」/「無差別轟炸 就緒」。
- **連結**（攜手之伴）：選這張牌時指定一位隊友，兩人就「連結」起來（雙向，整場冒險有效）。任何一方受到傷害時（敵人、Boss、誤傷都算），
  先照平常算完（含減傷、狂熱），再 -30%，然後跟活著的連結對象平分（除不盡的餘數算被打的人的，分到 0 就不分）；分到的那份不會擊退。
  對象倒下時不分也不減；落水不分。一個人可以被好幾位隊友連結，被打時跟所有活著的連結對象平分。
  同一發炸到好幾個人時，誰活著、誰有無敵都照爆炸之前算，所以結果跟角色順序無關；有神佑之石無敵的人，這一下（自己被打到 + 分到別人的份）全部擋掉，無敵只用掉一次。
  無差別轟炸炸到連結的隊友時，持有者一樣會分到那一份（轟炸本身還是炸不到他）。
  血條左邊的小環 = 連結生效中，分擔時兩人之間會閃一下。
  選牌時，這一輪已經選你連結的隊友不能再選回去（兩人選完本來就會連上），選牌畫面會自動把他拿掉。
- **暫時加成**（腎上腺素）：只在拿到之後的**下一關**有效：開打時血量上限 +100 並同時回 100 血、武器傷害 +50%；
  那一關打完就失效，血量超過原本上限的部分會被扣掉（沒超過就不動）。倒下的人一樣先照原本的上限復活，再加上去。
- **看隊友的牌**：孤狼傳說（場上沒有活著的隊友才生效，單人一直算）、團結力量大（每個活著的隊友算一次，只有自己有）。
  人數照「這一下打中之前」的場面算：自己這一發把隊友炸死，這一下還不算孤狼。
- **準備 / 狂獵**（磨刀霍霍 / 越戰越強）：每次**自己開的一槍**結算完才更新層數，所以這一槍吃的是開槍前的層數。
  「命中」= 這一槍（含等離子的兩發、波及）有打到任何一個敵方角色，傷害 0 也算（例如閉上的古樹之口）；只打到隊友、地形、落水、飛出場都算沒命中。
  轟炸不算射擊；回合超時沒開槍不會變。層數每關重新從 0 開始。底部狀態列會顯示目前層數。
- **嗨到最高點**：狂熱生效時（一般小關，幾輪開始見上面「狂熱」）武器傷害 +50%，不隨狂熱層數加倍；Boss 關沒有狂熱，所以沒效果。
- **狂歡派對**：這一關的狂熱提早從第 2 輪就觸發（見上面「狂熱」）。
- **受虐**（被虐體質）：每受到一次攻擊、**真的扣到血**就疊一層（敵人的攻擊、Boss 招式、誤傷、連結分到的那份、被打下來的鐘乳石都算；被無敵擋下、傷害 0 不算；
  中毒、流血、燃燒、落水、石假面扣的血也不算），每層武器傷害 +10%，最多 +40%（疊到 4 層就不再加）；層數每關從 0 開始，狀態列顯示「受虐 +N%」。
- **威嚇**：距離 = 從自己的身體中心量到對方身體最近的邊（`config.EQUIP.intimidate.range`，250），看傷害結算那一下雙方站在哪：
  打在這個距離內的敵人身上傷害 +20%（轟炸也算），這個距離內的敵人打自己（含 Boss 的招式）傷害 -10%（跟其他減傷相加）。
  用身體撞人的招式（武器的 `bodyHit`：大樹守衛衝鋒、蜜蜂螫擊、巨蟒衝撞）量撞上那一下的位置，不是出發的地方（從遠處衝過來撞到自己也算近的）。
  自己的回合在身上畫一圈很淡的虛線範圍（別人的回合不畫；有遮光的洞穴地圖畫在遮光上面）。
- **全力一擊**：看結算那一下自己剩多少體力：全滿 +10%、用完 +50%，中間照比例。自己操作時照開火那一刻回報的體力（伺服器只收比現在少的），
  斷線代打照模擬走路扣的；回合開始的無差別轟炸時體力是滿的（+10%）。狀態列即時顯示「全力 +N%」。
- **免疫異常狀態**（金剛不壞）：被打中時不會燃燒、中毒、流血（本來會上的那一下飄「免疫」）；傷害、擊退照常。
- **石假面**：自己的回合結束時（時間扭曲的額外回合也算）扣目前血量的 5%（四捨五入），最多扣到剩 1 血、不會因此倒下；
  直接扣（不吃狂熱、減傷，無敵也擋不住），算進承受傷害、不算「受到攻擊」（被虐體質不疊層）。牌上另外有傷害吸血 +30%。
- 參數都在 `config.EQUIP`（連結的減傷在 `EQUIP.link.damageCutPct`）。

## 肉鴿流程

- 一場冒險 = **10 關**（`RUN.stageCount`），**第 5、10 關是 Boss 關**（`RUN.bossStages`），**第 3、8 關是菁英關**（`RUN.eliteStages`，見「菁英關：地心探險」「菁英關：大樹守衛」「菁英關：流浪劍士」「菁英關：天狗」「菁英關：大樹遊俠」「菁英關：調皮妖精」「菁英關：頑皮猴王」），其他是小關。
- **難度**（2026-10-19，開房 / 單人練習時選，一整場冒險都一樣；設定 `config.DIFFICULTY`，換算成那一場的設定在 `shared/game/stage-rules.js` 的 `difficultyConfig`，
  `Run` 收 `difficulty`、一路傳給每一關的 `Match`）：**一般** = 上面的數字；**菁英之路** = **第 2、3、4、7、8、9 關都是菁英關**（只剩第 1、6 關是小關；
  每個菁英關打完一樣有稀有度加成），**敵人傷害整場不打折**（×1，含菁英怪與 Boss；一般難度第 1 ~ 5 關 ×0.7），
  **大樹守衛的躍擊、衝鋒、流浪劍士一閃的預警線不顯示**（躍擊的警示光柱、衝鋒的路線與目標準星、一閃對每個人的預警線都不畫；只是畫面，招式不變；`DIFFICULTY.rangeHints: false` → 地圖畫面的 `c.rangeHints`）。
  其他規則（血量、狂熱、Boss、抽牌）都一樣。
  每個小關隨機抽一張地圖：每張一開始機率一樣，這場冒險每出現過一次，之後被抽到的權重就 ×0.25（`RUN.normalRepeatWeight`），而且不會連續同一張；地圖池在 `shared/maps/level.js`（關卡的 `pool`：`normal` / `elite` / `boss`；第幾關是哪一種見 `shared/game/stage-rules.js` 的 `stageType`）。
  打贏第 10 關 = 通關；第 5 關的 Boss 打贏後跟小關一樣回血、選牌，再接著打下去。
  小關地圖：斷崖、雙塔、山谷、**樹影重重**（左邊一塊高地是出生點；右邊大樹上兩根樹枝站著 3 個**狙擊手**（左邊那根兩隻、右邊一隻），中間隔著水走不過去。
  樹枝跟 Boss 關的平台一樣炸不壞、子彈穿得過；大樹的樹幹與樹冠只是背景，子彈穿得過）、
  **腹背受敵**（中間一根高高的石柱是玩家的出生點，左右兩塊比較低的台地各站一個**砲兵**，中間隔著水）、
  **大亂鬥**（一整片平地，玩家從左邊出生，最右邊三個敵人，**種類每一場隨機**：一般敵人 / 狙擊手 / 砲兵，位置也隨機偏一點）、
  **小心擊發**（右邊一棵大樹（樹幹是炸不壞的樹皮）往左伸出一根樹枝，樹枝右邊站兩個狙擊手、最左邊掛著一個**蜂巢**，見下一節）、
  **岩穴**（洞穴地形：天花板垂下五根**鐘乳石**、洞裡很暗要點燃**火把**，右側高處的岩台上方、下方各飄著一隻**蝙蝠**，見「小關：岩穴」）。
- 小關敵人：一般敵人（`config.ENEMY`，大砲 + 狙擊槍、會走動）；**狙擊手**（`config.SNIPER`，基礎血量 30，只用狙擊槍、每回合在樹枝上走一段（不會走下樹枝），
  先挑直線打得到的人；角度誤差 `sniperSpread` ±3°，比一般敵人的 ±1.2° 鬆，因為一次有好幾隻）；**砲兵**（`config.ARTILLERY`，基礎血量 45，只用大砲、每回合在自己的台地上走一段；砲彈的擊退只有一般大砲的一半（`mods.knockbackPct: -50`），不然腹背受敵的窄石柱上幾乎每一發直擊都會把人打進水裡）；
  **蝙蝠**（`config.BAT`，基礎血量 45，飄在空中（不受重力、不會被擊退），每回合在出生點附近（左右 120、上下 40 px 內）直線飄一段，只用**聲波**：打法跟狙擊槍一樣（直線、會被地形擋住、角度誤差 ±3°），傷害 15、**擊退 120**（狙擊槍 90））。
  關卡的 `enemySpawns` 寫 `type: 'sniper'` / `'artillery'` / `'bat'` 就是狙擊手 / 砲兵 / 蝙蝠，`type: 'random'` 是每一場從 `randomEnemies.types` 隨機抽一種
  （用這一關的 seed 抽，伺服器與每個客戶端抽到的一樣；名字照抽到的種類取，例如「砲兵 B」）。
  只有狙擊槍的射手不會隔著自己人開槍：直線上擋著同伴的目標不打，每個人都被同伴擋住就那回合不開火（大亂鬥的平地上，排在後面的狙擊手要等前面的同伴讓開）。
- **敵人每回合都會走動**（2026-10-08，規則在 `shared/ai/ai-move.js`、參數 `config.AI_MOVE`；每種敵人照自己的 `moveChance`，目前都是 1）：開火 / 出招前先換位置，再從新的位置瞄準。
  站在地上的（一般敵人、狙擊手、砲兵、樹妖）走 30 ~ 80 px（照自己的速度換成幾幀，最多 90 幀；多半沿著上一回合的方向，走到底才回頭），每一步先看前面：
  沒有地面、往下超過 40 px、會走進水裡、走出樹枝 / 石柱 / 台地就停；同一層的同伴至少隔 56 px，不會走進別人身體裡。
  蝙蝠在出生點附近的框框裡直線飄一段（碰不到岩台、鐘乳石、天花板）；獨眼巨人沿著自己那根岩柱的頂面走（見「菁英關」）；大樹守衛不另外走（衝鋒、躍擊本身就會換位置）。
  只有直線武器的狙擊手 / 蝙蝠不會走到被同伴擋住、或擋住同伴射線的地方（樹影重重左邊那根樹枝站兩隻，常常只能挪一小段）。古樹、巨蟒、蜜蜂有自己的動法，不走；
  斷線玩家的 AI 代打照舊有 60%（`AI_MOVE.takeoverChance`）的機率走一段，路上碰到火把 / 蛇血一樣會點燃 / 喝到（跟自己走過去一樣）。
  走完還在半空中（剛走下小台階、前面不安全或體力用完的那一刻腳還沒著地）就放開方向鍵落到站穩再瞄準開火。
  客戶端照 `aiTurn` 的 `walk: { dir, frames, fall }` / `glide: { dx, dy, frames }` 重播，`ai.turn` 紀錄也帶著。
- 每關勝利：全員回血（血量上限的 `RUN.healPctOnClear`，目前 10%），然後**每位玩家**從三張牌中選一張（30 秒沒選或斷線就隨機）。選完進下一關。
  **打贏菁英關的那次選牌**，綠 / 紫 / 金的機率各多 `RUN.eliteRarityBonus` 個百分點（綠 +10%、紫 +5%、金 +1%），多出來的從白卡扣（總權重不變，不會被稀釋；
  白卡不夠扣就扣到 0），選牌畫面會標出來。
- 菁英關：從菁英池（`pool: 'elite'`）抽地圖，同一場冒險先挑還沒打過的（目前菁英池有地心探險、大樹守衛、流浪劍士、天狗、大樹遊俠、調皮妖精、頑皮猴王七張，第 3、8 關從裡面隨機挑兩張不同的）。
  菁英關的數字照小關（血量吃人數 × 關數、敵人傷害倍率、狂熱都一樣），只是由一隻招式比較多、血比較厚的菁英怪鎮守；開場橫幅、左上的關卡標籤是紫色的「菁英關」。
- 血量、牌、加成與武器欄在關與關之間帶著走；倒下的隊友下一關以 50% 血復活。任何一關全隊倒下 = 冒險結束。
- 選牌超時或斷線時隨機選，但會盡量避開「要丟掉武器才能拿」的武器牌與沒有隊友可連的攜手之伴；
  隨機選到攜手之伴就隨機連結一位還沒連結（這一輪也還沒選他）的隊友。
- Boss 關從 Boss 池隨機抽一張：**古樹之庭**、**叢林巨蟒** 或 **巨蠍巢穴**（地圖的 `pool: 'boss'`）。**同一場冒險不會抽到同一隻王**，所以兩個 Boss 關是兩隻不一樣的王
  （Boss 關比 Boss 池多的話，全部打過一輪才會重複，而且不會連續同一隻）。
  主題王的地圖（例如**大地祭壇**）也是 `pool: 'boss'`，但關卡寫了 `themeOnly`：只有主題副本排得到，一般冒險的 Boss 池抽不到（`levelsInPool` 跳過它）。
- 小關的敵人血量每過一關 +15%；Boss 關的血量照 `config.TREE_BOSS` / `config.TREANT` / `config.SNAKE_BOSS` / `config.SCORPION` / `config.GAIA`（見下面幾節），吃人數放大，
  另外**從第一個王關之後每多一關 +15%**（`RUN.bossHpPerStage`）：第 5 關的王照原本的血量，**第 10 關的王 ×1.75**、主題副本第 11 關的主題王 ×1.9（後面幾關玩家的牌多、數值好，不加會太好打）。
  召喚的樹妖、閉目養神的回血也一起放大。
- 相關數值都在 `shared/core/config.js` 的 `RUN`。

## 勝者為王（3v3 對戰）

2026-10-29 加的對戰模式（名稱暫定）。兩隊（**藍隊** / **紅隊**，每隊最多 3 人）在一張對戰地圖上打一場，**一隊全倒 = 另一隊贏**（同一下兩隊最後的人一起倒下 = 平手）。
流程在 `shared/game/versus.js`（`Versus`，跟冒險的 `Run` 同一套介面，伺服器房間與單人練習都用它），數值在 `config.VERSUS`。

- **房間**：大廳選「勝者為王 3v3」再建立房間。新來的人自動分到人少的那一隊，可以按「加入這一隊」換隊（那一隊要有空位）。
  人不夠時**房主可以在空位加電腦玩家**（「＋ 電腦」），也可以移除；電腦玩家算人數（房間最多 6 個，含電腦玩家）、一直算準備好。
  所有真人都準備好、**兩隊都有人**（真人或電腦玩家，人數可以不一樣）才能開始。單人練習 = 自己在藍隊、其他 5 個位子都是電腦玩家。
- **血量**：每個人 **300**（`VERSUS.hp`；牌的血量加成照這個算），開局武器同冒險（大砲 + 狙擊槍）。
- **回合順序**：兩隊輪流（藍 1 → 紅 1 → 藍 2 → …），哪一隊先攻每一場隨機；人數不一樣的話多出來的排在最後。每回合 30 秒同冒險。
  藍隊從地圖左邊出生、紅隊從右邊。**同一隊（含自己）的誤傷 ×0.6**，打到另一隊全額；落水同冒險的玩家規則（扣最大血量的 30%、回到站穩的地方）。
- **電腦玩家**：每回合由 AI 打（跟斷線代打同一套：會走一段、挑對方血最少的人瞄準、避開會炸到隊友的落點；
  每一發拋射都會打到 / 炸到自己人（含自己，例如跟隊友一起被打進坑裡）時改用狙擊槍，打不到就這回合先不開火——冒險的斷線代打也一樣，敵人照舊）。
  真人斷線時一樣由 AI 代打、可以重連回來。
- **每一輪打完選牌**（`VERSUS.pickEvery`，1 = 每一輪：場上所有人各行動一次之後）：戰鬥暫停，**每個還活著的人三選一張牌**（`VERSUS.pickTime` 20 秒，超時 / 斷線隨機選；
  電腦玩家馬上選，挑稀有度最高的），選完**當場生效**（血量上限、速度、體型、武器欄、加成都換上；加血量上限的牌同時回等量的血），隔 1.5 秒（`resumeDelay`）開始下一輪。
  抽牌的稀有度照輪數算（同冒險的第幾關，最多算到第 10 關）。給隊友 / 全隊的牌（醫療包、祈願之杖、攜手之伴…）只算同一隊；
  **對戰不出的牌**：牌上有 `VERSUS.excludeKeys` 的效果（弒神者的對首領傷害、腎上腺素的下一關加成、狂歡派對的狂熱提早）。倒下的人不再復活、也不選牌。
- **狂熱**：不看人數，**第 11 輪起**所有傷害 +50%，之後每過 10 輪再疊一層（`VERSUS.feverEvery`，算法在 `shared/game/stage-rules.js`，關卡的 `pool: 'versus'`）。
- **對戰地圖**（`shared/maps/level.js` 的 `pool: 'versus'`，冒險不會抽到）：**王者擂台**（左右兩塊高台，中間一座小島、缺口跳得過去）、**雙峰谷**（兩邊高、中間低的一整片山谷，谷底一個小土丘擋直線）。
  左右對稱，`teamSpawns` = 左隊、右隊的出生點；沒有敵人、沒有地圖機制。
- **結算**：打完先看 2.5 秒，再出結算畫面（勝利 / 落敗 / 平手、哪一隊贏、打了幾輪），兩隊分開列每個人的造成 / 承受傷害、命中率、擊殺、誤傷隊友、拿到的牌。
- 實作：隊伍是角色的 `team`（`blue` / `red`），「是不是玩家角色」另外看 `isPlayer`（`controller === 'human'`，含電腦玩家）；`Match.result()` 回傳贏的那一隊。
  裁判的 `onRoundEnd` 在一輪打完、下一輪開始前停下來交給 `Versus` 選牌；選完的牌用 `Match.refit` 套到場上的角色，伺服器與客戶端照同一份 `carry`（`roundPicks` 訊息）各套一次，
  重連的人照更新過的 `match.carry` 建出一樣的角色。

## 主題副本（莫利亞森林）

2026-11-02 加的冒險模式：**一整場冒險都在同一種地形**，最後一關是**主題王**（比以往的王更需要合作）。大廳的模式選「主題副本」（有開放中的主題才出現；目前只有一個主題，選了就是它），
單人練習、建立房間都可以；人數、選牌、回血、狂熱、敵人血量成長都照一般冒險（見「肉鴿流程」）。設定在 `config.THEMES`，換算成那一場的設定在 `shared/game/stage-rules.js` 的 `themeConfig` / `runConfig`
（難度再套主題），每一關排哪張地圖在 `shared/game/themes.js`（`themeLevels`）；`Run` 收 `theme`，房間是 `mode: 'theme'` + `theme`。

- **莫利亞森林**（`THEMES.moria`）：**11 關**。第 2、4、7、9 關是**菁英關**（大樹守衛、大樹遊俠、調皮妖精、頑皮猴王，整場各一次）；
  第 5 關**古樹之庭**、第 10 關**叢林巨蟒**、第 11 關主題王**大地祭壇（大地之母・蓋亞）**是固定的 Boss 關；其他是小關，只抽森林地圖（樹影重重、小心擊發、倒木溪谷、樹屋，整場不重複）。打贏第 11 關 = 通關。
- **難度**：一樣可以選。菁英之路在主題裡**不改菁英關的位置**，只留**敵人傷害整場不打折**、**不畫招式的提示範圍**。
- 王的血量照主題的 Boss 關成長（同 `RUN.bossHpPerStage`，從第 5 關算起每多一關 +15%）：第 10 關 ×1.75、**第 11 關 ×1.9**。

- 房間、大廳列表標主題的名字；`room.create` / `room.start` 與冒險的紀錄、`stageInfo`、`runOver` 帶 `theme`。

## 小關：小心擊發（蜂巢與蜜蜂）

右邊大樹的樹枝（平台：炸不壞、子彈穿得過）右邊站兩個狙擊手，**狙擊手全倒就過關**；樹枝最左邊下面掛著一個**蜂巢**，打不打都可以。規則在 `shared/maps/hive.js`。

- **蜂巢**（`config.HIVE`）：5 血，**不管用什麼武器、傷害多高、直擊或爆炸波及，被打到一次就只扣 1**（一顆飛行物算一次，等離子兩發都打到 = 扣 2）。
  **每被打到一次就飛出一隻蜜蜂**（打掉蜂巢的那一下也會飛出來，所以最多 5 隻）。蜂巢不會輪到它、不會燃燒、不會被擊退，打掉不算擊殺。
  只有玩家方的攻擊算數：敵人自己的子彈會**穿過**蜂巢與蜜蜂（也不擋狙擊手的視線）。斷線代打的 AI 不會去打蜂巢，拋射時也會避開會波及蜂巢的落點；加上瞄準誤差之後會擦到蜂巢的話就重抽誤差（最多 6 次，都不行就用不加誤差的那一發）。
  蜂巢的血量畫在它下面一排小六角形（上面是樹枝）。
- **蜜蜂**（`config.BEE`）：基礎血量 30（跟一般敵人一樣依人數、關數放大），飛在空中（不受重力、不會被擊退、不會落水），從蜂巢下面的 `level.mechanic.beeSpots` 找空位停著。
  排在回合順序的最後面：飛出來之後的**第一個自己的回合先待機**（`waitTurns: 1`），**下一個回合衝向離牠最近的玩家**（直線、穿過地形；中間剛好有別的玩家就先螫到那個人），
  **15 傷害（×敵人傷害倍率：第 1 ~ 5 關 0.7 = 11，第 6 關起 15）+ 10 層中毒，螫完就死掉**（`diesOnSting: true`）。所以每隻蜜蜂最多螫一次，飛出來之後有一整輪可以先把牠打掉。
  同一發先放出蜜蜂又把牠打死（例如無差別轟炸）也算擊殺。神佑之石的無敵擋得住（傷害與中毒都沒有；擋下來蜜蜂一樣力竭死掉）。
  中毒照 `config.POISON`（在自己的回合開始結算、層數不會自己消失；這張地圖沒有蛇血，一直到這一關結束）。
  `diesOnSting: false` = 螫完不會死，停在那位玩家身體旁邊（好幾隻時互相錯開、不停進地形裡），之後每個回合再衝。
- 右上的名單「敵人剩餘」只算狙擊手，後面另外標場上的蜜蜂數。
- **樹枝是狙擊手的掩體**（2026-10-08 改，`level.platformCover: 'enemies'`）：玩家的子彈打不穿樹枝（撞到就在樹枝上爆炸、彈射的會彈開），
  直線打不到樹枝上的狙擊手，要用拋物線從上面打（落在樹枝上的爆炸炸得到他們）——往樹枝打就更容易擦到底下的蜂巢。
  狙擊手自己的子彈照樣穿過樹枝往下打；人站在樹枝上的規則不變。斷線代打的 AI 也照這個判斷視線。

## 小關：岩穴（洞穴地形與蝙蝠）

一整片地面，天花板是炸不壞的岩石，右側高處一層岩台（平台：炸不壞，跳不上去），**岩台上方、下方各飄著一隻蝙蝠**，**蝙蝠全倒就過關**。
規則在 `shared/maps/cave.js`（地圖機制 `mechanic: { type: 'cave', torches }`），照明在 `client/map-views/cave.js`。

- **岩台是蝙蝠的掩體**（2026-10-22 改，`level.platformCover: 'enemies'`，同小心擊發的樹枝）：玩家的子彈打不穿岩台（撞到就在岩台上爆炸、彈射的會彈開），
  上面那隻要用拋物線從上面打，下面那隻直線打得到。蝙蝠的聲波照樣穿過岩台往下打。玩家打下來的鐘乳石也會落在岩台上碎掉（砸不到下面那隻）。

- **鐘乳石**（`level.stalactites`，地形的一種）：天花板垂下來的，擋子彈、擋人、炸不壞（坑挖不掉）。**被打到就整根掉下來**：
  直擊那一根、或爆炸範圍碰到都算，**任何一方的攻擊都會**。掉下來的鐘乳石從尖端開始自由落下（`WEAPONS.stalactite`），
  **砸到第一個角色就造成 30 傷害**（算打下它的人的攻擊：吃他的加成與狂熱、砸到自己人 ×0.6），沒砸到人就落地碎掉（不挖坑）。
  右邊兩根在岩台上方（砸得到上面那隻蝙蝠），最左邊那根在出生點上面（小心別把自己頭上的打下來）。
- **火把**：洞裡很暗，只有**出生點那支一開始亮著、光很微弱**；地上（岩台正下方）、岩台上各有一支要點燃。
  點燃的方法：玩家方的攻擊**打在火把旁邊**（落點離火把 `CAVE.torchReach` 24px 內，爆炸再加上爆炸半徑）、**子彈從火把旁邊飛過去**（`CAVE.torchPass` 10px + 子彈的判定半徑），
  或**自己走過去碰到**。敵人的攻擊不會點燃火把。
- **火把會燒完**：點燃的那一輪最亮（亮度 `CAVE.torchRounds` = 3），**之後每一輪開始暗一格（光圈變小），3 輪後熄滅**（3 → 2 → 1 → 熄）。
  「一輪」= 所有玩家、所有敵人各行動一次（`match.round`，跟狂熱同一個輪數），不是每個人的回合。一開始就亮著的出生點火把也一樣（第 1 輪最亮、第 4 輪熄）。
  **隨時都能補滿**：還亮著但變暗了的火把，打在旁邊、子彈飛過、走過去碰到都會補回最亮（飄「火把補滿！」，光圈、火焰從現在的大小長回去）；一直沒人去點才會慢慢熄掉，熄了一樣可以再點（算重新點燃，飄「火把點燃！」）。
  光圈半徑：最亮時 `CAVE.torchLight` 270px（出生點那支 `faintLight` 150px），最暗那一格 ×`dimLight` 0.45，中間照比例。
  亮度不另外存：狀態記「第幾輪點燃的」，亮度照輪數推，伺服器、客戶端、重連算得一樣。
- **火把是火源**（2026-10-22，著火的共同設定見「裝備的特殊狀態」的**著火**）：**任何一方**的子彈穿過**亮著的火把**（判定同上面的「子彈飛過去」）就著火，

- **猴王**（`config.MONKEY`）：血量 200，跟一般敵人一樣依人數、關數放大。站在樹枝上（fixed：不受重力、不會被擊退、不走動）。造型：棕色的毛、米色的臉和肚子、捲尾巴、小金冠。
- **接住**（地圖機制的 `passed`）：玩家方的飛行物（大砲、等離子飛彈、飛鏢、轟炸飛彈、迴力鏢；`MONKEY.catchable`）**從他身邊 100 px 內飛過、不會直接打中他** → 被他接住：
  飛行物到此為止（事件 `snatch`，不爆炸、不挖地），**手上多一顆**（最多 3 顆，滿了就接不了）。判定：這一幀在範圍內、已經過了最靠近他的那一點（這一幀比上一幀離他遠），
  而且照現在的樣子飛下去第一個撞到的不是他（`seg.ahead()`：拿一份複本試飛）——**會直接打中他的照常打中**。**狙擊槍、高壓水炮、西洋刺劍接不到**。
  他身邊畫一圈虛線（接住範圍）；手上的砲彈一顆顆浮在他頭上，右上的名單寫著是誰的。
- **打中拿著砲彈的他**（玩家方的任何攻擊碰到他，地圖機制的 `absorbHit`）：大家扣完血之後，**手上的砲彈全部在他身上炸開**（照原本的武器、攻擊者 = 打中他的人：
  算他的傷害、吃他的加成；只炸猴王自己），手上清空。炸開的那幾下由各自的 applyExplosion 算統計，不接進那一下的傷害清單（統計才不會算兩次）；事件帶 `monkey: { burst, dmg }` 給畫面飄字。吸血不算這幾下。
- **生氣**：血量掉到 **40% 以下**（燃燒燒下去的也算：照血量推，`isAngry`），接住範圍變成 **150**（虛線圈變橘色），之後一直生氣。這一趟已經打中（穿過）他的飛行物不接（例如迴力鏢去程）。
- 他的回合（`MONKEY.cast` = 每一步的預兆秒數）：
  1. **丟回去**：手上的砲彈一顆一顆丟回給**各自開槍的人**（`WEAPONS.monkeyThrow` 換成原本武器的傷害、爆炸範圍、擊退、挖不挖地）：拋物線瞄他身體中心**左右偏 0 ~ 60 px**（`throwError`，使用者要的誤差）的那一點，
     路上被地形擋住就打在地形上。開槍的人倒下了那顆就丟掉（`drop`）。
  2. **出一招**（`MONKEY.weights`，使用者要求每回合都出、接砲彈是額外的）：
     - **椰子砸**（60%，12 × 人數）：拋向隨機一名活著的玩家，偏 0 ~ 30 px。
     - **香蕉皮**（40%）：丟在隨機一名活著的玩家**左邊或右邊 40 ~ 90 px 的地上**（往下找第一個站得住的地方）。場上最多 3 張，滿了 / 兩邊都放不下就改丟椰子。
  3. **盪樹枝**：抓著藤蔓盪到另一根樹枝（隨機，不會留在同一根），轉向最近的玩家。
- **香蕉皮**（地圖機制的 `moved`）：玩家**走路**踩到（那一段路經過它、腳跟它一樣高，含起點：被炸過去、跳上去站在上面的一走就滑；原地 / 直直落下、跳過去的不算；香蕉皮不會丟在有人站的地方）→ 往走的方向**被迫滑行 150 px**（`Entity.slide`：每秒 360 px、貼著地形走、不耗體力），
  香蕉皮消失；**滑出平台 / 滑到坑邊就直直掉下去**（掉進泥水坑照一般落水規則），滑行中跳不起來。沒滑完不算站穩（settle 會滑完）；套用伺服器的狀態、時間到都停下。被任何爆炸炸到的香蕉皮消失（地圖機制的 `struck`，事件帶 `peelGone`）。
  自己的畫面在本地先判到就先滑（`predictMove`），伺服器照位置回報再判一次、廣播 `pickup`（`type: "peel"`）；AI 代打走路踩到就放開方向鍵、在 `walk.fall` 的幀裡滑完（跟著 `aiTurn` 的 `pickups` 在那一幀開始滑）。開火時還在滑也停下來。
- 都再 × 敵人傷害倍率（一般難度第 1 ~ 5 關 ×0.7；菁英之路不打折）。

## Boss 關：巨蠍巢穴（洞穴巨蠍）

洞穴裡一整片地面（可破壞，底下沒有水），牆上三個洞（背景，人走得過去），**洞穴巨蠍**躲在其中一個。兩個洞中間各一座兩層的**岩台塔**
（平台：炸不壞、子彈穿得過；每層 65px，從地面跳得上低層、從低層跳得上高層）。每個洞頂上垂一根鐘乳石；**每個洞左邊各一支火把**（一開始都熄著；
光圈 330，比一般的 270 大，點亮時整個洞都照亮），三支在**不同高度**（地面 / A 塔高層 / B 塔低層），一發狙擊最多只點得亮兩支。
**多人時會颳風**（`mechanic.windy`，單人不吹）：每一輪開始一陣強風把火把全部吹熄，畫面上飄過一道道風、字幕「颳起一陣強烈的風」；只有這一輪點燃的火把亮著。
單人的火把照一般洞穴（三輪燒完、隨時補滿）。
洞穴的規則（鐘乳石、火把、照明、陰影）跟岩穴一樣；規則在 `shared/maps/scorpion.js`（地圖機制 `mechanic: { type: 'scorpion', torches, holes, ground, start, windy }`，
`holes[i].torch` = 這個洞的火把，洞穴的部分沿用 `cave.js`），畫面在 `client/map-views/scorpion.js`（洞是關卡的裝飾 `decor.burrows`，畫在地形後面）。

- **躲著 / 出洞**：
  - **躲著**：縮在洞的深處，畫面上只有**洞穴中間一對發紅的雙眼**（在陰影裡時紅光比較大）。三個部位**碰不到**
    （角色的 `intangible`：子彈穿過去、爆炸波及不到、鐘乳石砸不到、AI 代打不瞄）。開場躲在最右邊的洞（離出生點最遠）。
  - **被火光逼出來**（單人、多人都一樣）：巨蠍躲的那個洞的火把一亮（打在旁邊、子彈飛過、走過去碰到），牠**馬上從地底升上來、出洞並暈眩**
    （打得到，頭上轉星星）。牠鑽進一個火把亮著的洞時當下不算，要到**下一輪開始、這一輪的火把算好之後**（多人颳風吹熄、單人變暗 / 燒完）還亮著，
    那時候才被逼出來（不會出現「暈眩了、火把卻是暗的」）。伺服器與客戶端照同一個條件各自推，不另外廣播。
- **三個部位**各是一個固定不動的角色、各有自己的血量（`SCORPION.hp`：背甲 150 / 巨鉗 110 / 毒針 80，照 Boss 的倍率放大），**打到哪個扣哪個**；
  **三個都擊破 = 打倒**（沒有另外的本體血量）。背甲 = 身體（最大塊）、巨鉗 = 頭前面的鉗子（低）、毒針 = 尾巴翹起來的尖端（最高、最小）。右上的名單有三個部位的血量與每回合動幾次。
- **巨蠍的回合**（由還沒擊破的第一個部位代表輪回合，一輪只有一次）：
  - **暈眩中**（`stunned`）：什麼都不做，留在洞口。
  - **出洞（暈眩醒來）**：**震擊周圍**（`shock`：從洞口中間往兩邊衝到洞口邊，`WEAPONS.scorpionBurst`：20 × 敵人傷害倍率、往外推 220，
    只打**站在那個洞口前面地上**的人）→ **還沒擊破的部位各出一招**（一回合最多三招；**每擊破一個部位就永久少一招**）→ **鑽地換洞**（隨機換到**別的洞**、面向玩家那邊、躲著；
    那個洞的火把下一輪開始還亮著才又被逼出來、暈眩）：
    - 巨鉗 → **巨鉗夾擊**：夾 `pinchReach` 260 px 內離鉗子最近的人（`scorpionPinch`：24、往外甩 320）；範圍裡沒人就撲空。
    - 背甲 → **甲殼地鳴**：震波從身體中間貼著地面往兩邊跑到地圖邊（`scorpionQuake`：18、擊退 160），**地上的人都會被震到**（含巨蠍身體底下），站在岩台上 / 半空中的不會。
    - 毒針 → **毒刺**：**每位玩家各射一發**（`scorpionSting`：12 + 2 層中毒、直線、穿過地形）。這張圖沒有蛇血，毒解不掉。
  - **躲著**：不出來，只從洞穴中間的雙眼那裡**對每位玩家各射一發毒刺**（毒針被擊破了就什麼都不做 `lurk`）。
  所以要打牠得先點亮牠那個洞的火把：牠暈眩的那一輪大家都打得到，下一輪牠醒來全力出招後就換洞。
  每一招的預兆時間照 `SCORPION.cast`（裁判照招式帶的 `cast` 算這回合要播多久）。
- **巨蠍出洞時的攻擊不吃陰影加成**（暈眩是給玩家的獎勵；醒來那一回合火把常常剛被風吹熄 / 變暗，不該反過來變懲罰）；躲在暗處射的毒刺照樣 +30%。
- 巨蠍出洞時把洞頂的鐘乳石打下來，會砸到牠（先砸到最高的毒針；30，算玩家的攻擊）；躲著的時候砸不到。
- 背景音樂 `sneaky-desert-scorpion.mp3`（洞穴地圖那首的 Boss 版）。

## Boss 關：古樹之庭

地圖：一片地面（可破壞）+ 三個一階一階往右上爬的浮空平台（低台 / 中台 / 高台，每階 65px）。
**平台炸不壞、子彈穿得過**（大砲、狙擊、長矛…都直接穿過去），人可以站在上面，也可以從下面直接跳上去、在底下橫著穿過去。
古樹長在最右邊，樹幹是**炸不壞的樹皮**，角色也走不到樹幹上（`level.maxX`）。古樹身上只有兩個打得到的地方：

| 部位 | 血量 | 說明 |
| --- | --- | --- |
| 古樹之眼 | 300 | 本體，輪到古樹時由它出招。**打倒 = 過關**（第 10 關的王打倒才是通關），嘴巴與場上的樹妖一起枯萎 |
| 古樹之口 | 打不壞 | 不會輪到它行動。**被攻擊到（直擊或爆炸波及）就閉上**，閉著的時候古樹不能召喚（多久再張開見下面「單人 / 多人」） |

眼睛與樹妖的血量跟一般敵人一樣每多一位玩家 +50%，但不吃小關的「每過一關 +15%」，改吃 Boss 關的成長（第 10 關 ×1.75，見上面「肉鴿流程」）。弒神者（`bossDamagePct`）對眼睛有效，對樹妖無效。
眼、嘴固定在樹上，不會被擊退；它們半個嵌在樹幹裡，砲彈打在旁邊的樹皮上也會被爆炸波及。
嘴巴不會受傷、不會燃燒；只有玩家的攻擊會讓它閉上（樹妖的長矛不會）。嘴巴的狀態不用文字標示，只看得到它張開或闔上。

**單人 / 多人**（以這一關的玩家人數判斷，1 人 = 單人；參數在 `TREE_BOSS`）：

| | 單人 | 多人 |
| --- | --- | --- |
| 嘴巴被打閉上後 | 多一回合冷卻：這一輪與**下一輪**的古樹回合都不能召喚，第二個古樹回合結束才張開（`mouthClosedTurnsSolo: 2`） | 只擋下一個古樹回合，那個回合結束就張開（`mouthClosedTurnsMulti: 1`） |
| 一次召喚幾隻 | 1 隻 | 玩家人數 × `summonPerPlayer`（1）隻，不超過 `maxMinions` |
| 召喚的回合 | 只召喚，預定的招式留到下一個不召喚的古樹回合 | 預定的是撞擊或落葉就接在召喚後面一起出（`attackOnSummonMulti`）；閉目養神 / 發呆留到之後 |

閉著的嘴巴再被打到，冷卻會重新計算。

古樹的**下一招是事先決定好的**：開場大家落地後先抽一次，之後每次用掉，就在那個古樹回合結束（擊退落地）後再抽下一招。
古樹撞擊在抽到的當下就選好平面，**玩家的回合裡那條橫掃範圍會一直標成紅色警示帶**，可以趁自己的回合離開；
飛散落葉、閉目養神、發呆不預告。

古樹的回合：

1. **士兵召喚**（最優先，不在預定裡，出招當下才看嘴巴）：嘴巴還張著、場上樹妖不滿 `maxMinions`（4）隻 → 一定召喚
   （預定的招式怎麼處理見上表）。樹妖從嘴巴吐出、落在樹根前的地面，**下一輪**才開始行動。打閉嘴巴，古樹就會直接出預定的招式。
2. 否則出預定的那一招。預定的招式依權重 `TREE_BOSS.weights` 抽（預設 40 : 40 : 10）：
   - **古樹撞擊**（40）：抽到的當下挑「站最多玩家」的平面（平手隨機）；出招時不管玩家現在在哪，巨大樹幹都從樹身沿那個高度往左橫掃，打中那個平面上的每位玩家 50 傷害、擊退 60。出招前那條範圍會快速閃紅。
   - **飛散落葉**（40）：出招時才挑離古樹最近的玩家飛過去，直線前進、穿過地形與角色，路線上每位玩家各 30 傷害、擊退 40。
   - **閉目養神**（10）：只有抽的當下眼睛受過傷才會抽到；回復眼睛 100 血（跟血量一樣隨人數放大）。
   - `idle`（0）：發呆。想要「40% / 40% / 10%，剩下的機率什麼都不做」就把它設成 10。

古樹的攻擊與樹妖的長矛都不會打到自己人（`passAllies`）。**樹妖**（`config.TREANT`）每回合慢慢走一段、投擲長矛（拋物線、傷害 25、不挖地、只打直接命中）。

地圖可以用的地形種類（`shared/maps/level.js`）：`polygons`（土，炸得掉）、`hardPolygons`（實心、炸不掉）、
`platforms`（炸不掉、子彈穿得過、只有從上面落下來站得住，**頂面要畫成水平的**）、`vines`（可以攀爬的藤蔓 `{ x, top, bottom }`，見下一節）。

## Boss 關：叢林巨蟒

地圖：一條**藤蔓橋**（平台：炸不壞、子彈穿得過）從左邊一路接到巨蟒嘴前，橋下全是水；上面垂下三條**藤蔓**。
巨蟒的頭在最右邊，那裡沒有橋：走過橋的盡頭、被甩過去都會掉進水裡（照落水規則扣 30%）。

- **爬藤蔓**：按住 `W`（或 `S`）時身體碰到藤蔓就抓住。站在橋上搆不到藤蔓的下端，要先跳起來（按著 `W` 跳就會抓住）。
  抓著時不受重力、可以照常瞄準開火（藤蔓上瞄準不會慢動作）；`W` / `S` 上下爬（每秒 100px、跟走路一樣耗體力）。
  自己的回合掛著不動也要耗體力（`PLAYER.vineHangCost`，每秒 20），體力用完就鬆手掉下去（沒體力也抓不住）。
  按著 `W` / `S` 就是抓緊；沒按時 `A` / `D` 放手。`空白鍵` 跳開（跟站在地上起跳一樣，同時按 `A` / `D` 就往那邊跳）；往下爬到手滑過下端就掉下去；
  被擊退會被打下藤蔓。回合結束（開火、超時）時體力還沒用完、還掛著，就一直掛到下一個自己的回合（別人的回合不耗體力）。
  藤蔓的上端在上方 HUD 下面一段，爬到最上面頭上的資訊也不會被 HUD 擋住。
- **巨蟒**（`config.SNAKE_BOSS`）：整顆頭都打得到（判定是橢圓），血量 400（每多一位玩家 +50%；不吃小關的關數放大，改吃 Boss 關的成長：第 10 關 ×1.75），打倒 = 過關。弒神者對它有效。
- 巨蟒的**下一招是事先抽好的**（開場一次、之後每出一招就再抽），權重 `weights`：

| 招式 | 機率 | 效果 |
| --- | --- | --- |
| 巨蟒衝撞 | 45% | 整顆頭沿著橋往左衝到底：範圍是**頭的上緣到水面**，橋上的人、抓在藤蔓下段的人受到 **30 傷害 + 3 層中毒**（被撞到會往左彈一下、撞下藤蔓）。**抽到時玩家回合會一直畫出紅色警示帶**，爬到警示帶上面就躲得掉 |
| 毒液噴灑 | 25% | 從嘴巴往左上方隨機散射 6 顆毒液（拋物線，穿過橋掉進水裡），打中的人 **10 層中毒**；同一次噴灑每人最多中一次。藤蔓上的人也會被噴到 |
| 大地震擊 | 10% | 震波沿著橋面跑，**站在橋上的人**受到 50 傷害、**往巨蟒的方向擊退 500**（離巨蟒近的會被甩下橋掉進水裡）。藤蔓上、半空中的人不會被打到 |
| 劇毒撕咬 | 20% | 咬**離巨蟒嘴巴最近**的玩家：15 傷害 + **10 層中毒**（藤蔓上的也咬得到，會被咬下來） |

  巨蟒的傷害一樣吃敵人傷害倍率（第 5 關 ×0.7：衝撞 21、震擊 35、撕咬 11；第 10 關 ×1：30、50、15）；中毒層數不受影響。衝撞 / 噴灑的傷害、衝撞 / 撕咬的擊退在 `config.WEAPONS.snake*`。
- **中毒**（`config.POISON`）：在被毒的人**自己的回合開始時**結算——每層扣最大血量 1%（照現在的上限算），**同時把最大血量鎖住一樣多**
  （100/100 中 1 層 → 99/99）。**層數不會自己消失**：每個自己的回合開始都再結算一次，再被打中還會疊上去，**要喝蛇血才解毒**（`POISON.persist: false` = 舊規則，結算完就歸零）。被鎖住的上限在血條右邊畫成灰色（底部狀態列寫成「現在 / 鎖住後的上限（原本的上限）」），
  回血都只能回到鎖住後的上限。不吃減傷、狂熱；神佑之石的無敵會擋掉上毒的那一下；攜手之伴只分傷害、不分毒。毒不夠扣就被毒倒，那個回合不會開始。
  身上的層數標在血條旁邊（紫色毒液滴）。
- **蛇血**（紅色的小瓶子）：巨蟒每受到最大血量 20%（`bloodEveryPct`）的傷害就從嘴裡掉出一瓶，落在橋上靠近巨蟒的那一段（`level.mechanic.bloodX`），
  一下打很多會一次掉好幾瓶，被燒到跨過門檻也會掉。**自己的回合走過去就喝掉**（回合開始時就站在上面也算），
  **解毒**（層數歸零）、把被鎖住的上限**全部解開，再回 15 血**（`bloodHeal`，不超過上限；10/50(100) → 25/100）。沒中毒、沒被鎖住又滿血的人走過去不會撿（留給需要的人）。

## 主題王：大地祭壇（大地之母・蓋亞）

主題副本「莫利亞森林」的第 11 關、最後一關（關卡 `gaiaSanctum`：`pool: 'boss'` + `themeOnly`，一般冒險抽不到）。**地形全部炸不壞**：
左右各三道往中間斜下來的**斜坡**（`hardPolygons`，18 px 厚；`level.js` 的 `GAIA_SLOPES`，內側端點 y 440 / 510 / 580），中間三層平的**平台**（`GAIA_TIERS`：上層 y 440、**祭壇** y 510、下層 y 580；
可穿透：往上跳穿過上面那層、往下走出邊緣掉下去）。每一層都跳得到（沒有二段跳，見 `test/gaia.js`）。底下是一片有毒的水（`waterColors` 深紫 → 深綠，掉下去照落水規則）。
玩家從祭壇那一層出生，**打倒蓋亞就通關**。
規則在 `shared/maps/gaia.js`（地圖機制 `mechanic: { type: 'gaia', face, altar, column, slopes, tiers, shield, lightSpots }`），畫面在 `client/map-views/gaia.js`。

- **蓋亞**（`config.GAIA`）：背景正上方一張巨大的大地之臉（固定、一直打得到；判定 `hw` 90 / `h` 190，腳底 = 下巴在 `mechanic.face`），左右兩隻巨掌只是畫面、不是角色。
  血量 500 × Boss 倍率（第 11 關 ×1.9、每多一位玩家 +50%）。一輪裡玩家先、蓋亞最後：「她的第 N 回合」= 第 N 輪。
- **瘴氣**：第 1 輪她的回合就放，之後每 3 輪（`fogEvery`）：**全畫面的毒霧**，瘴氣還在時每個玩家自己的回合開始 **+3 層中毒**（`fogPoison`，同巨蟒的中毒；免疫異常狀態的人不疊；
  中毒先結算才疊，新疊的下一個自己的回合才咬人）。同時在**不同的斜坡**上各開一朵**自然之花**（照活著的人數 `flowers`：1 ~ 3 人 2 朵、4 人 3 朵；開在斜坡的 20% ~ 80% 之間）。
  重放瘴氣時舊的花消失、祭壇的光球歸零。
- **自然之花 → 祭壇**：玩家的身體碰到花就撿到（走路、跳、被擊退飛過去都算，AI 代打走路也算），變成一顆光球飛進祭壇。**收滿了 = 祭壇淨化**：瘴氣散去、花清掉、
  活著的玩家**中毒層數歸零**（被鎖住的上限不回來）、**回 10% 最大血量**（`purifyHealPct`），蓋亞**下一回合暈眩**（只有暈眩：不放瘴氣、不出招）。下一次瘴氣照原本的輪數。
- **招式**（每回合一招，事先抽好 = 預定的下一招，權重 `weights`：捏碎 30 / 天罰 30 / 同罰 25 / 淨化 15，我補的；加同罰之前使用者定的是 40 / 40 / 20）：
  - **巨掌・捏碎**（`WEAPONS.gaiaCrush`）：兩隻手在**中間那一整欄**（`mechanic.column`：三層平台那一欄、整個畫面高度）合起來，身體碰到那一欄的人 **每人 10 × 開場人數的傷害（1 ~ 4 人 10 / 20 / 30 / 40，`gaiaDamage`）、往離開祭壇的方向擊退 500**
    （祭壇左邊往左、右邊往右，往上彈一點；可能被甩進毒水）。
  - **神掌・天罰**（`WEAPONS.gaiaSmite`）：一隻手掌拍下**左邊或右邊整片**（三道斜坡；抽招的時候就決定哪一邊），那一邊的人 **每人 9 × 開場人數的傷害（9 / 18 / 27 / 36）、往牆那邊推 100**。兩掌的傷害都照開場人數（含之後倒下的），再吃一般的敵人傷害倍率。
  - **巨拳・同罰**（`WEAPONS.gaiaStack`，11-04 使用者加的：拳頭鎖定一名玩家的頭上、要有聚攏提示、讓大家一起分擔傷害）：抽招的時候就**鎖定隨機一名活著的玩家**，
    玩家回合她那一邊的手握成石拳、一直跟在他頭上。她的回合：**身體中心離他 80 px 以內**（`stackRadius`，含他自己）的活著的玩家**平分總傷害**
    **20 × 開場人數**（1 ~ 4 人 20 / 40 / 60 / 80，`gaiaDamage`；每人 round(總傷害 / 人數)，再吃敵人傷害倍率），每個分擔的人頭上各落下一記拳；不擊退。
    一個人扛就是全部。最後之光那幾回合照樣會放；放最後之光的那一回合，分擔的人照傳送前（玩家回合照集合圈站好）的位置算（數字與這兩條都是我補的）。
  - **自然・淨化**（11-04 使用者改：只淨化她自己、會回血）：綠色光球在她嘴邊聚起來、吸回臉上，**移除她自己的負面狀態**（中毒層數、燃燒、流血、糾纏；
    被中毒鎖住的上限不回來，同玩家的祭壇淨化），**固定回 5% 最大血量**（`cleanseHealPct`，我補的；沒有負面狀態也回）。不碰玩家、沒有傷害。
  - 捏碎、天罰是每個被打到的人各一道震波（同獨眼巨人的震盪獅吼），客戶端照事件重播飛出去。出招時預定的不能用了（最後之光那幾回合預定了捏碎）就重抽；同罰的目標倒下了只換一個活著的目標、招式不變（我補的：不會出沒預警過的捏碎 / 天罰）。
  - **預兆**：一般難度在玩家回合畫紅色警示帶（捏碎 / 天罰的範圍）與**同罰的集合圈**（目標身上半徑 `stackRadius` 的圈、往裡指的箭頭、「集合分擔（N 人）」、圈裡的人腳下亮起來）；
    **菁英之路只看得到巨掌的架勢**（`c.rangeHints`；同罰的石拳照樣跟在目標頭上，不畫集合圈）。
- **暴走**：血量到 **50%**（`ragePct`）先停在門檻（同蜘蛛女王），輪到她才宣告暴走：瘴氣**永久不散**（祭壇不再淨化、不再暈眩她）、花清掉，之後回合開始每次 **+1 層**（`ragePoison`）；
  暴走那一回合照樣出招。暈眩的那一回合先暈完，下一回合才暴走。
- **最後之光 → 誅滅**：暴走後第 5 輪（`lightEvery`）她的回合放**最後之光**：活著的人全部**傳送到祭壇那一層**，照活著的人數在不同的斜坡上開花（`lightFlowers`：1 / 2 / 3 / 4 人 = 2 / 4 / 4 / 6 朵）。
  之後兩輪（`lightCollectRounds`）玩家收花，**收齊了祭壇張開護盾**；第二輪她的回合還沒收齊 → 剩下的花「**因為自然的力量枯萎了**」。再一輪玩家回到祭壇，她的回合**誅滅**：
  **不在護盾裡的人直接死亡**（不吃無敵、減傷、免疫，剩下的血全算承受傷害；沒有護盾 = 全滅），在裡面的人中毒層數歸零（護盾的範圍是 `mechanic.shield`：腳底在祭壇那一層上）。
  之後再數 5 輪。最後之光那幾回合（放的那一回合到誅滅那一回合）**不放捏碎**。HUD 顯示最後之光的倒數，放了之後顯示現在該做什麼（收花 / 回到祭壇 / 誅滅）。
- 她的回合（`GAIA.cast` = 每一步的預兆秒數）：暈眩 → 只有 `stunned`；不然 → 暴走（`rage`）→ 瘴氣（`fog`）或 誅滅 / 枯萎 / 最後之光（`judgement` / `wither` / `light`）
  → 預定的那一招（`crush` / `smite` / `stack` / `cleanse`；什麼都沒做是 `idle`）→ 抽下一招。
- 招式傷害都再 × 敵人傷害倍率（第 11 關 ×1；菁英之路也是 ×1）。

## 牌庫

牌在 `shared/cards/cards.json`，改完存檔即可，**下一場開局**就會讀到，不用重啟伺服器。每張牌：

```json
{ "id": "heavy_shell", "name": "重型砲彈", "rarity": "green",
  "desc": "大砲傷害 +20%、爆炸半徑 +10%",
  "effects": { "cannonDamagePct": 20, "radiusPct": 10 },
  "unique": false, "minStage": 1 }
```

武器牌多一個 `weapon` 欄位（值是 `config.WEAPONS` 裡的武器 id，目前可用 `cannon` / `sniper` / `boomerang` / `plasma` / `darts` / `waterCannon` / `rapier`），可以不寫 `effects`：

```json
{ "id": "boomerang", "name": "迴力鏢", "rarity": "green", "weapon": "boomerang",
  "desc": "擲出後飛到最遠處（力量越大飛越遠，撞到地形會提早折返）再沿原路飛回身上，去程、回程都會打到路上的敵人（不會打到隊友）。傷害 25，不會炸地形" }
```

- `rarity`：`white` 白 / `green` 綠 / `purple` 紫 / `gold` 金。抽牌權重在 `config.RUN.rarityWeights`，每過一關紫、金的權重會增加。
- `unique: true` 的牌一位玩家只會拿到一次；`minStage` 是第幾關起才會出現。
- 自動過濾：已經在武器欄裡的武器不會再出；效果**全部**只對某把武器有用的牌（例如只有 `sniperDamagePct`），
  玩家沒有那把武器時也不會出；效果全部要有隊友才有用的牌（`allyHeal` / `allyDamagePct` / `allyArmorPct` / `link`）單人冒險不會出；
  已經跟所有隊友連結了，就不會再出有 `link` 的牌。

每個**效果**（見 GLOSSARY.md）是 `shared/cards/effects/` 裡的一個檔案：上表的鍵與說明、數值、選牌當下 / 下一關的行為、戰鬥規則、
效果自己的角色狀態與同步欄位、開火紀錄的欄位，以及狀態列 / 飄字 / 橫幅要顯示什麼，都寫在那個檔案裡；
`shared/cards/effects/index.js` 是登記表（上表的鍵、哪些是立即效果 / 武器限定 / 多人限定、戰鬥的 mods 都從這裡算出來），也寫了每個掛勾的說明。

- 新增一張用現有效果的牌：只改 `cards.json`。
- 新增一個效果：`shared/cards/effects/` 加一個檔案，`index.js` 的 `LIST` 最後面加一行，上表最後加一列（說明跟效果檔案寫的一字不差，備註可空），
  再加用它的牌；不用改測試（步驟與各掛勾見 `shared/cards/effects/index.js` 開頭）。`test/effects.js` 會檢查 key / 狀態欄位沒重複、掛勾名字沒寫錯、
  上表跟效果檔案的說明一致。
- 改一個效果：只改它自己的檔案。效果之間誰先誰後（例如武器傷害的各項怎麼相加、爆炸裡減傷與連結的順序、選牌的兩輪回血）在 `match.js` / `run.js` 決定。

## 調參數

所有數值都在 `shared/core/config.js`：血量、體力與消耗、每回合秒數、誤傷倍率、敵人血量放大率、狂熱（幾輪一層、每層 +多少%）、落水扣血比例、
武器傷害/半徑/初速、瞄準手感、大砲預覽點數、AI 誤差、流程節奏。改完重啟伺服器並重新整理頁面。

## 紀錄（LOG）

伺服器會把每一場的過程記在 `logs/game-YYYY-MM-DD.log`（一天一個檔、本機日期；玩家看不到）。啟動時終端機會印出這次寫在哪個檔。
單人練習的裁判在瀏覽器裡跑，紀錄每 2 秒（或離開頁面時）送回伺服器（`POST /log`）寫進同一個檔，房號標成 `SOLO-xxxx`；
伺服器正在重開時會先攢著、晚點重送（最多 5000 筆，再多丟最舊的並記一筆 `log.dropped`）。
開關在 `shared/core/config.js` 的 `LOG`：`enabled` 總開關、`moves` 移動回報要不要逐筆記（量最大，每人每秒最多 10 筆）、`dir` 資料夾。
**每個動作都要記**：收訊息的兩個入口（伺服器的 `RoomManager.onMessage`、單人的 `LocalTransport.send`）會檢查每一則訊息都留下至少一筆紀錄，
處理途中一筆都沒記就補一筆 `msg.unlogged`；客戶端送來的值寫進紀錄前一律經過 `logValue`（截短、物件只記型別）。
裁判照樣記每一次移動，`moves` 關掉時由寫檔的地方（`RoomManager.record`、`SoloLog.record`）不寫。
寫的時候檔案或資料夾被刪掉，一秒內會自己重建。

每行一筆 JSON，前三個欄位固定是 `ts`（時間，到毫秒）、`ev`（事件）、`room`（房號）；玩家用 `pid`（玩家 id）＋ `name`（暱稱）表示。
回合類的事件（`turn.*`、`ai.turn`）用 `actor` 表示輪到誰（玩家或敵人的 id），是玩家的話另外帶 `pid`。
遊戲中的事件另外帶 `stage`（第幾關）、`round`（第幾輪）。例如：

```json
{"ts":"2026-10-02 14:03:22.123","ev":"fire","room":"K7QX","stage":1,"round":2,"pid":"Zx3…","name":"甲","weapon":"cannon","angle":47.5,"power":63,"x":212,"y":431}
{"ts":"2026-10-02 14:03:22.124","ev":"shot","room":"K7QX","stage":1,"round":2,"kind":"weapon","pid":"Zx3…","name":"甲","weapon":"cannon","hit":"entity","frames":88,"kills":["e2"],"changes":[{"id":"e2","name":"小怪 2","hp":[40,0],"died":"hit"}]}
```

`changes` = 這次結算前後血量有變的角色（`hp: [之前, 之後]`，`died` = 這次倒下、`spawned` = 新召喚的）。
用房號找一場：`findstr K7QX logs\game-2026-10-02.log`。

### 同步方式（一回合）

1. 伺服器廣播 `turn`（含所有角色的狀態快照）。
2. 行動玩家在自己瀏覽器裡即時移動，每 100ms 回報位置（`move`），其他人插值顯示。
   回報也帶 `hp`（自己畫面上的血量：流血時走路扣的血由他自己的畫面先扣，伺服器在他流血時照收、只減不加；落水那次帶落水之前的），
   伺服器轉給其他人的 `move` 在他流血時也帶 `hp`（別人的畫面位置馬上套、血量照順序排在佇列裡：畫面落後時，之後才播的舊快照不會把血量蓋回去）；
   在自己的畫面流血扣到倒下就馬上送一筆 `hp: 0` 的 `move`，伺服器跳過這回合（`skip`，`reason: 'bleed'`；流血來源有擊殺的效果時帶 `fx`，客戶端照效果飄字）。
   自己的畫面上回合時間到了就停下、不能再操作（不再走路流血），還沒回報的位置 / 血量馬上補送一次，之後照伺服器超時的 `skip` 套最後的狀態。
3. 放開滑鼠送 `fire`（武器、角度、力量、位置）。
4. 伺服器用共用邏輯逐幀算完所有飛行物（連射、彈射、穿透、迴力鏢折返與回程打到的敵人、射程到了消散），廣播 `shot`：
   每顆飛行物的出發幀與初速，以及事件清單（第幾幀、哪顆、爆炸 / 穿透 / 彈射 / 折返 / 射程到了（`range`）、挖坑（不挖地形的爆炸帶 `blast`）、傷害（免疫異常狀態擋下燃燒 / 中毒 / 流血的那一筆帶 `immune`）、受影響角色的狀態）。
   後座力（高壓水炮）不另外送：客戶端擺好射手後照第一顆的初速推一次，跟伺服器同一套算法。
   飛鏢射完一支還有次數時，伺服器不換人，等這一支播完再廣播 `resume`（剩下的秒數、還能射幾次），行動玩家接著操作。
5. 所有瀏覽器照同樣的幀序重播：飛行只跑運動學，撞擊結果照事件套用，最後再校正成伺服器的結果。
6. 敵人或斷線玩家的回合由伺服器算好整段腳本（走路幾幀、瞄哪、結果）一次廣播 `aiTurn`。
   走路是 `walk: { dir, frames, fall }`：按著方向走 `frames` 幀，再放開方向鍵跑 `fall` 幀落到站穩（走完還在半空中時；平常 0），
   客戶端照同一套物理逐幀重播，瞄準、開火前一定站在地上；蝙蝠 / 獨眼巨人是 `glide: { dx, dy, frames }`（伺服器直接放到終點，客戶端照 `glideAt` 逐幀內插）。
   斷線代打的玩家走路途中撿到的道具（點燃火把、喝到蛇血）放在 `pickups`（跟 `pickup` 訊息同樣的欄位，多一個 `f` = 走到第幾幀撿到的，客戶端播到那一幀才套上）。
   走路 / 飄移途中流血倒下、算到流血來源的擊殺時，擊殺的效果另外記的放在 `fx`（例如噬魂者；跟 `turnFx` 同一套），客戶端走完才飄字。
   斷線代打的玩家在流血時，AI 不會選會讓他流血扣到倒下（或只剩 1 點）的走法（都會的話這回合不走）。
   古樹的回合也是 `aiTurn`，多一個 `boss.steps`：依序播放的招式（多人召喚的回合可能是「召喚、預定的攻擊」兩招），
   每一招帶目標平面 / 目標、召喚的樹妖資料（`spawns`）、回血量；撞擊與落葉的結果放在該招的 `shot`（`kind: 'boss'`），
   召喚 / 閉目養神放在該招的 `still`；`boss.next` 是這回合之後預定的下一招（客戶端整回合播完才換上，撞擊的預告因此留到真的撞下去）。
   重連時快照的 `minions` 讓客戶端重建樹妖，`treeNext` 帶著預定的下一招。
7. 回合開始的無差別轟炸也是一個 `shot`（`kind: 'bombard'`）；回合結束的效果用 `turnFx` 廣播：
   燃燒、流血止血（`bleed`）、神佑之石、時間扭曲的額外回合（`extraTurn`）、石假面扣血（`stoneMask`），以及古樹回合結束時嘴巴重新張開（`mouthOpen`）。
8. 行動玩家回報位置（`move`）時也帶垂直速度：回合超時或斷線時，伺服器從他回報的空中狀態接著落地（例如往上跳穿平台的途中）。
   抓著藤蔓時帶 `vine`（第幾條），伺服器確認掛得上去才算；角色狀態的 `vn` / `ps` / `lk` / `bl` = 抓著的藤蔓 / 中毒層數 / 被鎖住的上限 / 流血層數
   （`bl` 在 `toState` 排在 `lk` 後面、`toEventState` 排在 `ps` 後面；流血不足 1 點的小數不同步，套快照時兩邊都從 0 開始，AI 走路 / 飄移扣的血才重播得一模一樣）。
   掛著耗的體力只在行動玩家自己的畫面扣（`Entity.hangDrain`，照 `move` / `fire` 的體力回報），伺服器結算、別人的回合都不扣，所以回合結束時掛著就一直掛著。
   慢動作也只在行動玩家自己的畫面：`main.js` 每一步 update 的 dt 乘上 `GameView.timeScale`（開火、播事件腳本時一定是 1，重播才跟伺服器的固定步長一致）；
   開 / 關時送 `slow`（`on`、`why`），裁判記 `slowmo` 並轉給其他人（`slow`：`id`、`on`），其他人在他身上畫淡藍色光環。
9. 叢林巨蟒的回合也是 `aiTurn` 的 `boss.steps`（一招，帶 `shot`）。打到巨蟒跨過門檻掉的蛇血放在 `shot` 事件的 `drops`；
   走路途中喝到蛇血由伺服器廣播 `pickup`（給所有人，包括他自己；帶上限與血量，自己先預測喝過就不再套）；`turn` 與快照帶著場上的 `items`、`snakeNext`。
10. 小心擊發：打到蜂巢飛出來的蜜蜂放在那個 `shot` 事件的 `bees`（出生資料：id、名字、位置、血量、待機次數），客戶端在那一幀照著建出來；
   快照的 `bees` 讓重連的客戶端重建，角色狀態的 `wt` = 蜜蜂還要待機幾回合。蜜蜂的回合也是 `aiTurn` 的 `boss.steps`（`wait` 帶 `still`、`sting` 帶 `shot`：
