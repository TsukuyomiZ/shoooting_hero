# Shooting Hero（彈彈堂風格 PVE 共鬥，最多 4 人）

純 HTML5 Canvas + vanilla JS 客戶端，Node + `ws` 伺服器。同一份遊戲邏輯（`shared/`）在伺服器與瀏覽器上跑，
伺服器是唯一的裁判，瀏覽器只送輸入、收結果播動畫。

## 執行

```bash
npm install
npm start
```

然後開 <http://localhost:8123>。伺服器啟動時會印出區網 IP，朋友在同一個網路下用那個網址就能加入。
放到公網時請放在有 TLS 的反向代理後面（wss），或用 Render / Fly.io / Railway 之類的平台。

> 現在用的是 ES modules，直接雙擊 `index.html` 會被瀏覽器擋住，一定要透過伺服器開。

### 同事連不進來？

1. 確認同事用的是伺服器印出的「區網」網址（例如 `http://172.23.192.67:8123`），而且跟你在同一個網路。
2. 多半是 Windows 防火牆擋了 Node.js 的連入（第一次開埠時的防火牆詢問按了取消，就會留下「封鎖」規則）。
   以**系統管理員**開 PowerShell 執行：

   ```powershell
   Set-NetFirewallRule -DisplayName "Node.js JavaScript Runtime" -Action Allow -Profile Domain,Private
   ```

   或走 GUI：開始 → 搜尋「允許應用程式通過 Windows 防火牆」→ 變更設定 → 勾選 Node.js JavaScript Runtime 的「網域」與「私人」。
   改完不用重啟伺服器。
3. 沒有管理員權限、或同事不在同一個網路：用免費的 Cloudflare 通道把伺服器暴露成公開網址（支援 WebSocket、自帶 TLS）：

   ```powershell
   winget install Cloudflare.cloudflared
   cloudflared tunnel --url http://localhost:8123
   ```

   把它印出的 `https://xxxx.trycloudflare.com` 網址給同事即可。

## 大廳

- **單人練習**：不連線，裁判直接在瀏覽器裡跑，流程跟多人完全一樣。
- 打開頁面就會連上伺服器，選單下方的 **大廳 · 公開房間** 即時列出所有公開房間（房號、房主、人數，點一列就加入；
  遊戲中 / 已滿的灰掉不能點）。連不上伺服器時列表顯示「重試」，單人練習照樣能玩。
- **建立房間** → 拿到 4 碼房號；旁邊勾 **私人房間** 就不會出現在大廳列表，只能輸入房號進場。
  房主在房間裡可以隨時切換公開 / 私人（其他人只看得到標籤）。
- **輸入房號加入**：公開、私人房間都能用房號進場。
- 所有人按「準備」後，房主按「開始遊戲」。遊戲開始後不能再加入。
- 標題旁是版本階段（目前 **BETA**）。大廳下方是 **版本履歷**：直接條列每一版改了什麼（新增 / 調整 / 修正，最新的在最上面、預設展開，
  舊版本點一下展開），右邊的「收合」按鈕把整塊收起來（記在瀏覽器裡；出了新版本會自動再展開，最新那版標 `NEW`）。

## 版本

版本號設定與版本履歷都在 `shared/version.js`：

- `VERSION`：`channel` 是階段（`'ALPHA'` / `'BETA'` / `''` = 正式版），`number` 是版本號；畫面上顯示成 `BETA v1.2`。
- `CHANGELOG`：版本履歷，新的在最上面；每一筆 `{ version, channel, date, title, new: [...], change: [...], fix: [...] }`
  （新增 / 調整 / 修正，沒有的種類省略）。
- **改版時**：改 `VERSION.number`（要換階段就改 `channel`），在 `CHANGELOG` 最上面加一筆同版本號的紀錄，
  `package.json` 的 `version` 跟著改（`1.2` BETA → `1.2.0-beta`）；還沒改版前的改動就加在最上面那一筆裡。
  `npm test` 的 `test/version.js` 會檢查三個地方對得上、版本與日期由新到舊。
- 伺服器啟動（`server.start`）與單人練習開始（`solo.start`）的紀錄會帶 `version`，查 LOG 時知道是哪一版玩的。

## 操作

| 按鍵 / 滑鼠 | 動作 |
| --- | --- |
| `A` / `D` | 左右移動（每秒消耗 45 體力，空中也能微調） |
| `空白鍵` | 跳躍（消耗 30 體力，可以跳過缺口）；有雲霧之瓶時在空中可以再跳一次 |
| `W` / `S` | 爬藤蔓（叢林巨蟒）：按住時身體碰到藤蔓就抓住，往上 / 往下爬（跟走路一樣每秒消耗 45 體力）；自己的回合掛著不動也每秒消耗 20 體力，體力用完就鬆手掉下去；按著 W / S 就是抓緊（邊走邊跳過去也抓得住），沒按時 `A` / `D` 放手；`空白鍵` 從藤蔓上跳開（同時按 `A` / `D` 就往那邊跳） |
| 按住滑鼠左鍵 | 開始瞄準：滑鼠方向 = 角度，拖曳距離 = 力量（10~100）。**跳起來之後瞄準會進入慢動作**（要真的按了跳；走下坡、走下台階、被打飛的離地都不算）：整個畫面慢 80%（只剩 20% 的速度），每秒（真實時間）消耗 50 體力，體力歸零、落地或抓到藤蔓就解除；回合倒數照真實時間走 |
| 放開左鍵 | 發射並結束本回合（空中也能開火：從當下的位置出手，之後照原本的速度落下） |
| `1` / `2` / `3` | 切換武器欄第 1 / 2 / 3 格的武器（也可點畫面上方按鈕） |
| `R` | 結束後回到大廳 |
| `M` | 背景音樂靜音 / 恢復成原本的音量 |
| 右上角喇叭按鈕 | 音量設定：音樂、音效各一條滑桿（0~100，會記住，下次進來照舊）；`Esc` 或點面板外面關閉 |
| 右下角貼圖按鈕 | 丟反應貼圖：像彈幕一樣從畫面右邊飄到左邊，所有人都看得到；只走畫面最上方一排（不擋戰場），同時很多張會排隊依序飄（誰丟的會標名字；自己丟的有外框）。任何時候都能按，選牌時也行；每人 3 秒內最多 4 張 |

### 新增反應貼圖

圖檔放 `assets/stickers/`（建議正方形、透明背景，32~64px），然後在 `shared/stickers.js` 的 `STICKERS` 加一行
`{ id: '英數字代號', label: '滑鼠移上去的說明', src: 'assets/stickers/檔名' }`，重啟伺服器、重新整理頁面即可。洗版上限也在同一個檔案（`STICKER_LIMIT`）。

### 背景音樂與音效

小關放 `assets/music/canyon-echoes.mp3`，狂熱生效（4 人第 8 輪、2 ~ 3 人第 9 輪、1 人第 10 輪起）的那一刻交叉淡入 `canyon-fever.mp3`；
古樹之庭放 `guardian-of-the-canopy.mp3`（原曲；`client/ambience.js` 有合成樹葉聲可以疊上去，在 `TRACKS.tree` 加 `leaves: 1` 就會開）；叢林巨蟒放 `savage-jungle-menace.mp3`，進關時前一首很快收掉，先播一聲合成的蛇哈氣（`sfx.js` 的 `snakeHiss`，吃「音樂」音量），音樂接著淡入（時間和音量在 `music.js` 的 `HISS`）。
整首循環播放（曲尾本身有淡出，直接接回開頭）；切到別的分頁、縮小視窗時音樂和音效照樣播（同時開好幾個分頁測多人時，把其他分頁的音量拉到 0，免得好幾份聲音疊在一起）。
換曲、調曲子的相對音量、樹葉聲大小（`leaves`）改 `client/music.js` 最上面的 `TRACKS`；風多久一陣、葉子 / 風聲 / 脆響各多大聲在 `ambience.js` 最上面；哪一關放哪首在 `GameView.musicTrack()`（Boss 關問地圖畫面的 `musicTrack`，見 `client/map-views/`）。

音效全部用 Web Audio 即時合成（沒有音檔），在 `client/sfx.js` 的 `SOUNDS`：腳步、跳躍、大砲（等離子飛彈、迴力鏢也用這個）、
狙擊槍（後面帶兩聲山谷回聲）、爆炸（大坑 / 小坑兩種）、砲彈落水、角色落水、被打中。聲音會照發生的位置分左右聲道。
輪到自己的回合（單人、多人都一樣）會響「叮、叮、叮——」提示音（`yourTurn`，不分左右聲道）：平常跟「你的回合」橫幅一起響；
分頁在背景時畫面會落後，收到回合訊息就先響（`GameView.cueTurn`）。AI 代打、重連回到自己的回合不響。
音量設定（音樂 / 音效兩條匯流排、存 localStorage）在 `client/audio.js`，面板在 `client/settings-ui.js`。
這些都只改前端，不用重啟伺服器，重新整理頁面就好。

## 規則

- 回合順序：玩家 1 → 2 → 3 → 4 → 敵人 A → 敵人 B，每回合 30 秒，回合開始體力回滿。
- 敵人血量隨人數放大：每多一位玩家 +50%。
- 敵人（含古樹、樹妖、巨蟒、狙擊手、砲兵、蜜蜂）造成的傷害 = 武器傷害 × 敵人傷害倍率（再吃狂熱）：
  **第一輪（第 1 ~ 5 關）×0.7**（`ENEMY.damageMult`），**第二輪（第 6 關起）×1**，不再抑制（`ENEMY.damageMultLate`、`lateFromStage`）。
- 隊友誤傷（含打到自己）傷害 ×0.6。
- **狂熱**：避免雙方血量太多、一關打太久。一般小關每過 N 輪（左上的「第 N 輪」），所有角色（玩家與敵人）造成的傷害 +50%，
  會疊加，每關重新從 0 算。誤傷、燃燒也吃這個加成，回血不受影響。N 照這一關的玩家人數（人越多一輪越久，就越早狂熱）：

  | 人數 | 幾輪一層 | 第一層（+50%） | 第二層（+100%） |
  |---|---|---|---|
  | 4 人 | 7 輪 | 第 8 輪起 | 第 15 輪起 |
  | 2 ~ 3 人 | 8 輪 | 第 9 輪起 | 第 17 輪起 |
  | 1 人 | 9 輪 | 第 10 輪起 | 第 19 輪起 |

  **Boss 關不套用**（Boss 關有自己的機制）。疊上新的一層時橫幅會提示，生效中左上會有「狂熱」標籤。
  參數在 `CONFIG.FEVER`（`everyRounds: { 人數: 輪數 }`，填一個數字 = 不分人數、`0` = 關掉；`inBoss: true` = Boss 關也套用）。
- 上面的敵人血量 / 傷害倍率、狂熱，加上哪幾關是王關（`RUN.bossStages`）與王關的血量成長（`RUN.bossHpPerStage`），合起來是**關卡規則**（見 GLOSSARY.md）：
  數值照樣在 `shared/config.js`，算法全在 `shared/stage-rules.js` 一個檔案。一關開場就算好（`match.rules`）；第幾輪記在 `match.round`，
  狂熱層數 `match.fever` 由它推出，伺服器、畫面（HUD、橫幅、換狂熱曲、狀態列）都讀同一個。
- 有人斷線：輪到他時由 AI 代打（用他武器欄裡的武器）；重新整理頁面會用 token 自動回到原本的遊戲。
- 地形可破壞。**落水**：敵人（含樹妖）直接淹死。玩家扣最大血量的 30%（不吃狂熱、減傷、神佑之石），扣完沒血才會淹死；
  撐得住就馬上回到最後站穩的地方，那裡被炸掉了就找最近站得住的地面。自己的回合掉下去回合**不會結束**：
  還有體力就能接著走、照常開火、計時照走（方向鍵要放開重按才會再走，免得一回到崖邊又走下去）；淹死才結束回合。
  打進水裡淹死一樣算擊殺。參數在 `CONFIG.WATER`（`enemiesDrown: false` = 敵人也照玩家的規則）。
- 全部敵人倒下即勝利，全隊倒下即失敗。

### 武器

每個角色有一個**武器欄，最多 3 把**（`config.EQUIP.maxWeapons`）。開局是大砲 + 狙擊槍，
選牌時可能抽到武器牌：欄位沒滿就直接裝上；滿了就要先選一把丟掉（新武器放進被丟掉的那一格），也可以取消改選別張。
數值（傷害、半徑、重力、擊退）都在 `config.WEAPONS`。

- **大砲**：拋物線、會炸坑並擊退，瞄準時只顯示前 4 個點（有全知之眼時拋射武器都畫完整條拋物線與落點準星）。有蹦蹦炸彈時砲彈碰到地形先彈一次（跟哈哈子彈一樣照地表反射、不減速，彈的那一下不爆炸），下一次碰到東西才爆炸。
- **狙擊槍**：無重力直線飛行，瞄準時顯示完整路線（有哈哈子彈會畫出彈射後的路線，有高倍率望遠鏡會標出穿透點）。
- **迴力鏢**（武器牌）：拋物線，碰到東西後沿原路飛回角色手上；不爆炸、不挖地，只打直接命中的角色。
- **等離子飛彈**（武器牌）：同一條彈道隔 10 幀連射三發，每發傷害 30、都會爆炸挖坑。

### 裝備的特殊狀態

- **燃燒**：在自己的回合結束時，每層扣最大血量 0.1%；在自己的回合移動可以甩掉層數（每 10px 一層，每回合最多 10 層）。
- **無敵**（神佑之石）：擋下下一次傷害（也不會被擊退），不會疊加。
- **額外回合**（時間扭曲）：普通回合結束後馬上再輪到自己一次（完整回合：體力回滿、會觸發回合開始 / 結束的裝備效果，不算新的一輪）；
  之後要再過 3 個普通回合才會再給，額外回合本身不能再接額外回合。
- **無差別轟炸**：持有者的回合開始時先播轟炸，播完才開始計時；持有者左右 60px 內不落彈，其他地方（包括隊友）都會被炸。
- **連結**（攜手之伴）：選這張牌時指定一位隊友，兩人就「連結」起來（雙向，整場冒險有效）。任何一方受到傷害時（敵人、Boss、誤傷都算），
  先照平常算完（含減傷、狂熱），再 -30%，然後跟活著的連結對象平分（除不盡的餘數算被打的人的，分到 0 就不分）；分到的那份不會擊退。
  對象倒下時不分也不減；落水不分。一個人可以被好幾位隊友連結，被打時跟所有活著的連結對象平分。
  同一發炸到好幾個人時，誰活著、誰有無敵都照爆炸之前算，所以結果跟角色順序無關；有神佑之石無敵的人，這一下（自己被打到 + 分到別人的份）全部擋掉，無敵只用掉一次。
  無差別轟炸炸到連結的隊友時，持有者一樣會分到那一份（轟炸本身還是炸不到他）。
  血條左邊的小環 = 連結生效中，分擔時兩人之間會閃一下。
  選牌時，這一輪已經選你連結的隊友不能再選回去（兩人選完本來就會連上），選牌畫面會自動把他拿掉。
- **暫時加成**（腎上腺素）：只在拿到之後的**下一關**有效：開打時血量上限 +100 並同時回 100 血、武器傷害 +50%；
  那一關打完就失效，血量超過原本上限的部分會被扣掉（沒超過就不動）。倒下的人一樣先照原本的上限復活，再加上去。
- **看隊友的牌**：孤狼傳說（場上沒有活著的隊友才生效，單人一直算）、團結力量大（每個活著的隊友算一次，只有自己有）。
  人數照「這一下打中之前」的場面算：自己這一發把隊友炸死，這一下還不算孤狼。
- **準備 / 狂獵**（磨刀霍霍 / 越戰越強）：每次**自己開的一槍**結算完才更新層數，所以這一槍吃的是開槍前的層數。
  「命中」= 這一槍（含等離子的三發、波及）有打到任何一個敵方角色，傷害 0 也算（例如閉上的古樹之口）；只打到隊友、地形、落水、飛出場都算沒命中。
  轟炸不算射擊；回合超時沒開槍不會變。層數每關重新從 0 開始。底部狀態列會顯示目前層數。
- **嗨到最高點**：狂熱生效時（一般小關，幾輪開始見上面「狂熱」）武器傷害 +50%，不隨狂熱層數加倍；Boss 關沒有狂熱，所以沒效果。
- 參數都在 `config.EQUIP`（連結的減傷在 `EQUIP.link.damageCutPct`）。

## 肉鴿流程

- 一場冒險 = **10 關**（`RUN.stageCount`），**第 5、10 關是 Boss 關**（`RUN.bossStages`），其他是小關。每個小關隨機抽一張地圖（不會連續同一張），地圖池在 `shared/level.js`。
  打贏第 10 關 = 通關；第 5 關的 Boss 打贏後跟小關一樣回血、選牌，再接著打下去。
  小關地圖：斷崖、雙塔、山谷、**樹影重重**（左邊一塊高地是出生點；右邊大樹上兩根樹枝站著 3 個**狙擊手**（左邊那根兩隻、右邊一隻），中間隔著水走不過去。
  樹枝跟 Boss 關的平台一樣炸不壞、子彈穿得過；大樹的樹幹與樹冠只是背景，子彈穿得過）、
  **腹背受敵**（中間一根高高的石柱是玩家的出生點，左右兩塊比較低的台地各站一個**砲兵**，中間隔著水）、
  **大亂鬥**（一整片平地，玩家從左邊出生，最右邊三個敵人，**種類每一場隨機**：一般敵人 / 狙擊手 / 砲兵，位置也隨機偏一點）、
  **小心擊發**（右邊一棵大樹（樹幹是炸不壞的樹皮）往左伸出一根樹枝，樹枝右邊站兩個狙擊手、最左邊掛著一個**蜂巢**，見下一節）。
- 小關敵人：一般敵人（`config.ENEMY`，大砲 + 狙擊槍、會走動）；**狙擊手**（`config.SNIPER`，基礎血量 30，只用狙擊槍、站著不動，
  先挑直線打得到的人；角度誤差 `sniperSpread` ±3°，比一般敵人的 ±1.2° 鬆，因為一次有好幾隻）；**砲兵**（`config.ARTILLERY`，基礎血量 45，只用大砲、站著不動；砲彈的擊退只有一般大砲的一半（`mods.knockbackPct: -50`），不然腹背受敵的窄石柱上幾乎每一發直擊都會把人打進水裡）。
  關卡的 `enemySpawns` 寫 `type: 'sniper'` / `'artillery'` 就是狙擊手 / 砲兵，`type: 'random'` 是每一場從 `randomEnemies.types` 隨機抽一種
  （用這一關的 seed 抽，伺服器與每個客戶端抽到的一樣；名字照抽到的種類取，例如「砲兵 B」）。
  只有狙擊槍的射手不會隔著自己人開槍：直線上擋著同伴的目標不打，每個人都被同伴擋住就那回合不開火（大亂鬥的平地上，排在後面的狙擊手要等前面的同伴讓開）。
- 每關勝利：全員回血（血量上限的 `RUN.healPctOnClear`，目前 10%），然後**每位玩家**從三張牌中選一張（30 秒沒選或斷線就隨機）。選完進下一關。
- 血量、牌、加成與武器欄在關與關之間帶著走；倒下的隊友下一關以 50% 血復活。任何一關全隊倒下 = 冒險結束。
- 選牌超時或斷線時隨機選，但會盡量避開「要丟掉武器才能拿」的武器牌與沒有隊友可連的攜手之伴；
  隨機選到攜手之伴就隨機連結一位還沒連結（這一輪也還沒選他）的隊友。
- Boss 關從 Boss 池隨機抽一張：**古樹之庭** 或 **叢林巨蟒**（地圖的 `pool: 'boss'`）。**同一場冒險不會抽到同一隻王**，所以兩個 Boss 關剛好各打一次
  （Boss 關比 Boss 池多的話，全部打過一輪才會重複，而且不會連續同一隻）。
- 小關的敵人血量每過一關 +15%；Boss 關的血量照 `config.TREE_BOSS` / `config.TREANT` / `config.SNAKE_BOSS`（見下面兩節），吃人數放大，
  另外**從第一個王關之後每多一關 +15%**（`RUN.bossHpPerStage`）：第 5 關的王照原本的血量，**第 10 關的王 ×1.75**（後面幾關玩家的牌多、數值好，不加會太好打）。
  召喚的樹妖、閉目養神的回血也一起放大。
- 相關數值都在 `shared/config.js` 的 `RUN`。

## 小關：小心擊發（蜂巢與蜜蜂）

右邊大樹的樹枝（平台：炸不壞、子彈穿得過）右邊站兩個狙擊手，**狙擊手全倒就過關**；樹枝最左邊下面掛著一個**蜂巢**，打不打都可以。規則在 `shared/hive.js`。

- **蜂巢**（`config.HIVE`）：5 血，**不管用什麼武器、傷害多高、直擊或爆炸波及，被打到一次就只扣 1**（一顆飛行物算一次，等離子三發都打到 = 扣 3）。
  **每被打到一次就飛出一隻蜜蜂**（打掉蜂巢的那一下也會飛出來，所以最多 5 隻）。蜂巢不會輪到它、不會燃燒、不會被擊退，打掉不算擊殺。
  只有玩家方的攻擊算數：敵人自己的子彈會**穿過**蜂巢與蜜蜂（也不擋狙擊手的視線）。斷線代打的 AI 不會去打蜂巢，拋射時也會避開會波及蜂巢的落點；加上瞄準誤差之後會擦到蜂巢的話就重抽誤差（最多 6 次，都不行就用不加誤差的那一發）。
  蜂巢的血量畫在它下面一排小六角形（上面是樹枝）。
- **蜜蜂**（`config.BEE`）：基礎血量 30（跟一般敵人一樣依人數、關數放大），飛在空中（不受重力、不會被擊退、不會落水），從蜂巢下面的 `level.mechanic.beeSpots` 找空位停著。
  排在回合順序的最後面：飛出來之後的**第一個自己的回合先待機**（`waitTurns: 1`），**下一個回合衝向離牠最近的玩家**（直線、穿過地形；中間剛好有別的玩家就先螫到那個人），
  **15 傷害（×敵人傷害倍率：第 1 ~ 5 關 0.7 = 11，第 6 關起 15）+ 10 層中毒，螫完就死掉**（`diesOnSting: true`）。所以每隻蜜蜂最多螫一次，飛出來之後有一整輪可以先把牠打掉。
  同一發先放出蜜蜂又把牠打死（例如無差別轟炸）也算擊殺。神佑之石的無敵擋得住（傷害與中毒都沒有；擋下來蜜蜂一樣力竭死掉）。
  中毒照 `config.POISON`（在自己的回合開始結算、層數不會自己消失；這張地圖沒有蛇血，一直到這一關結束）。
  `diesOnSting: false` = 螫完不會死，停在那位玩家身體旁邊（好幾隻時互相錯開、不停進地形裡），之後每個回合再衝。
- 右上的名單「敵人剩餘」只算狙擊手，後面另外標場上的蜜蜂數。

## Boss 關：古樹之庭

地圖：一片地面（可破壞）+ 三個一階一階往右上爬的浮空平台（低台 / 中台 / 高台，每階 65px）。
**平台炸不壞、子彈穿得過**（大砲、狙擊、長矛…都直接穿過去），人可以站在上面，也可以從下面直接跳上去、在底下橫著穿過去。
古樹長在最右邊，樹幹是**炸不壞的樹皮**，角色也走不到樹幹上（`level.maxX`）。古樹身上只有兩個打得到的地方：

| 部位 | 血量 | 說明 |
| --- | --- | --- |
| 古樹之眼 | 300 | 本體，輪到古樹時由它出招。**打倒 = 過關**（第 10 關的王打倒才是通關），嘴巴與場上的樹妖一起枯萎 |
| 古樹之口 | 打不壞 | 不會輪到它行動。**被攻擊到（直擊或爆炸波及）就閉上**，閉著的時候古樹不能召喚（多久再張開見下面「單人 / 多人」） |

眼睛與樹妖的血量跟一般敵人一樣每多一位玩家 +50%，但不吃小關的「每過一關 +15%」，改吃 Boss 關的成長（第 10 關 ×1.75，見上面「肉鴿流程」）。弒神者（`bossDamagePct`）對眼睛有效，對樹妖無效。
眼、嘴固定在樹上，不會被擊退；它們半個嵌在樹幹裡，砲彈打在旁邊的樹皮上也會被爆炸波及。
嘴巴不會受傷、不會燃燒；只有玩家的攻擊會讓它閉上（樹妖的長矛不會）。嘴巴的狀態不用文字標示，只看得到它張開或闔上。

**單人 / 多人**（以這一關的玩家人數判斷，1 人 = 單人；參數在 `TREE_BOSS`）：

| | 單人 | 多人 |
| --- | --- | --- |
| 嘴巴被打閉上後 | 多一回合冷卻：這一輪與**下一輪**的古樹回合都不能召喚，第二個古樹回合結束才張開（`mouthClosedTurnsSolo: 2`） | 只擋下一個古樹回合，那個回合結束就張開（`mouthClosedTurnsMulti: 1`） |
| 一次召喚幾隻 | 1 隻 | 玩家人數 × `summonPerPlayer`（1）隻，不超過 `maxMinions` |
| 召喚的回合 | 只召喚，預定的招式留到下一個不召喚的古樹回合 | 預定的是撞擊或落葉就接在召喚後面一起出（`attackOnSummonMulti`）；閉目養神 / 發呆留到之後 |

閉著的嘴巴再被打到，冷卻會重新計算。

古樹的**下一招是事先決定好的**：開場大家落地後先抽一次，之後每次用掉，就在那個古樹回合結束（擊退落地）後再抽下一招。
古樹撞擊在抽到的當下就選好平面，**玩家的回合裡那條橫掃範圍會一直標成紅色警示帶**，可以趁自己的回合離開；
飛散落葉、閉目養神、發呆不預告。

古樹的回合：

1. **士兵召喚**（最優先，不在預定裡，出招當下才看嘴巴）：嘴巴還張著、場上樹妖不滿 `maxMinions`（4）隻 → 一定召喚
   （預定的招式怎麼處理見上表）。樹妖從嘴巴吐出、落在樹根前的地面，**下一輪**才開始行動。打閉嘴巴，古樹就會直接出預定的招式。
2. 否則出預定的那一招。預定的招式依權重 `TREE_BOSS.weights` 抽（預設 40 : 40 : 10）：
   - **古樹撞擊**（40）：抽到的當下挑「站最多玩家」的平面（平手隨機）；出招時不管玩家現在在哪，巨大樹幹都從樹身沿那個高度往左橫掃，打中那個平面上的每位玩家 50 傷害、擊退 60。出招前那條範圍會快速閃紅。
   - **飛散落葉**（40）：出招時才挑離古樹最近的玩家飛過去，直線前進、穿過地形與角色，路線上每位玩家各 30 傷害、擊退 40。
   - **閉目養神**（10）：只有抽的當下眼睛受過傷才會抽到；回復眼睛 100 血（跟血量一樣隨人數放大）。
   - `idle`（0）：發呆。想要「40% / 40% / 10%，剩下的機率什麼都不做」就把它設成 10。

古樹的攻擊與樹妖的長矛都不會打到自己人（`passAllies`）。**樹妖**（`config.TREANT`）站著不動、投擲長矛（拋物線、傷害 25、不挖地、只打直接命中）。

地圖可以用的地形種類（`shared/level.js`）：`polygons`（土，炸得掉）、`hardPolygons`（實心、炸不掉）、
`platforms`（炸不掉、子彈穿得過、只有從上面落下來站得住，**頂面要畫成水平的**）、`vines`（可以攀爬的藤蔓 `{ x, top, bottom }`，見下一節）。

## Boss 關：叢林巨蟒

地圖：一條**藤蔓橋**（平台：炸不壞、子彈穿得過）從左邊一路接到巨蟒嘴前，橋下全是水；上面垂下三條**藤蔓**。
巨蟒的頭在最右邊，那裡沒有橋：走過橋的盡頭、被甩過去都會掉進水裡（照落水規則扣 30%）。

- **爬藤蔓**：按住 `W`（或 `S`）時身體碰到藤蔓就抓住。站在橋上搆不到藤蔓的下端，要先跳起來（按著 `W` 跳就會抓住）。
  抓著時不受重力、可以照常瞄準開火（藤蔓上瞄準不會慢動作）；`W` / `S` 上下爬（每秒 100px、跟走路一樣耗體力）。
  自己的回合掛著不動也要耗體力（`PLAYER.vineHangCost`，每秒 20），體力用完就鬆手掉下去（沒體力也抓不住）。
  按著 `W` / `S` 就是抓緊；沒按時 `A` / `D` 放手。`空白鍵` 跳開（跟站在地上起跳一樣，同時按 `A` / `D` 就往那邊跳）；往下爬到手滑過下端就掉下去；
  被擊退會被打下藤蔓。回合結束（開火、超時）時體力還沒用完、還掛著，就一直掛到下一個自己的回合（別人的回合不耗體力）。
  藤蔓的上端在上方 HUD 下面一段，爬到最上面頭上的資訊也不會被 HUD 擋住。
- **巨蟒**（`config.SNAKE_BOSS`）：整顆頭都打得到（判定是橢圓），血量 400（每多一位玩家 +50%；不吃小關的關數放大，改吃 Boss 關的成長：第 10 關 ×1.75），打倒 = 過關。弒神者對它有效。
- 巨蟒的**下一招是事先抽好的**（開場一次、之後每出一招就再抽），權重 `weights`：

| 招式 | 機率 | 效果 |
| --- | --- | --- |
| 巨蟒衝撞 | 45% | 整顆頭沿著橋往左衝到底：範圍是**頭的上緣到水面**，橋上的人、抓在藤蔓下段的人受到 **30 傷害 + 3 層中毒**（被撞到會往左彈一下、撞下藤蔓）。**抽到時玩家回合會一直畫出紅色警示帶**，爬到警示帶上面就躲得掉 |
| 毒液噴灑 | 25% | 從嘴巴往左上方隨機散射 6 顆毒液（拋物線，穿過橋掉進水裡），打中的人 **10 層中毒**；同一次噴灑每人最多中一次。藤蔓上的人也會被噴到 |
| 大地震擊 | 10% | 震波沿著橋面跑，**站在橋上的人**受到 50 傷害、**往巨蟒的方向擊退 500**（離巨蟒近的會被甩下橋掉進水裡）。藤蔓上、半空中的人不會被打到 |
| 劇毒撕咬 | 20% | 咬**離巨蟒嘴巴最近**的玩家：15 傷害 + **10 層中毒**（藤蔓上的也咬得到，會被咬下來） |

  巨蟒的傷害一樣吃敵人傷害倍率（第 5 關 ×0.7：衝撞 21、震擊 35、撕咬 11；第 10 關 ×1：30、50、15）；中毒層數不受影響。衝撞 / 噴灑的傷害、衝撞 / 撕咬的擊退在 `config.WEAPONS.snake*`。
- **中毒**（`config.POISON`）：在被毒的人**自己的回合開始時**結算——每層扣最大血量 1%（照現在的上限算），**同時把最大血量鎖住一樣多**
  （100/100 中 1 層 → 99/99）。**層數不會自己消失**：每個自己的回合開始都再結算一次，再被打中還會疊上去，**要喝蛇血才解毒**（`POISON.persist: false` = 舊規則，結算完就歸零）。被鎖住的上限在血條右邊畫成灰色（底部狀態列寫成「現在 / 鎖住後的上限（原本的上限）」），
  回血都只能回到鎖住後的上限。不吃減傷、狂熱；神佑之石的無敵會擋掉上毒的那一下；攜手之伴只分傷害、不分毒。毒不夠扣就被毒倒，那個回合不會開始。
  身上的層數標在血條旁邊（紫色毒液滴）。
- **蛇血**（紅色的小瓶子）：巨蟒每受到最大血量 20%（`bloodEveryPct`）的傷害就從嘴裡掉出一瓶，落在橋上靠近巨蟒的那一段（`level.mechanic.bloodX`），
  一下打很多會一次掉好幾瓶，被燒到跨過門檻也會掉。**自己的回合走過去就喝掉**（回合開始時就站在上面也算），
  **解毒**（層數歸零）、把被鎖住的上限**全部解開，再回 15 血**（`bloodHeal`，不超過上限；10/50(100) → 25/100）。沒中毒、沒被鎖住又滿血的人走過去不會撿（留給需要的人）。

## 牌庫

牌在 `shared/cards.json`，改完存檔即可，**下一場開局**就會讀到，不用重啟伺服器。每張牌：

```json
{ "id": "heavy_shell", "name": "重型砲彈", "rarity": "green",
  "desc": "大砲傷害 +20%、爆炸半徑 +10%",
  "effects": { "cannonDamagePct": 20, "radiusPct": 10 },
  "unique": false, "minStage": 1 }
```

武器牌多一個 `weapon` 欄位（值是 `config.WEAPONS` 裡的武器 id，目前可用 `cannon` / `sniper` / `boomerang` / `plasma`），可以不寫 `effects`：

```json
{ "id": "boomerang", "name": "迴力鏢", "rarity": "green", "weapon": "boomerang",
  "desc": "擲出後碰到東西會沿原路飛回身上。傷害 25，不會炸地形" }
```

- `rarity`：`white` 白 / `green` 綠 / `purple` 紫 / `gold` 金。抽牌權重在 `config.RUN.rarityWeights`，每過一關紫、金的權重會增加。
- `unique: true` 的牌一位玩家只會拿到一次；`minStage` 是第幾關起才會出現。
- 自動過濾：已經在武器欄裡的武器不會再出；效果**全部**只對某把武器有用的牌（例如只有 `sniperDamagePct`），
  玩家沒有那把武器時也不會出；效果全部要有隊友才有用的牌（`allyHeal` / `allyDamagePct` / `allyArmorPct` / `link`）單人冒險不會出；
  已經跟所有隊友連結了，就不會再出有 `link` 的牌。
- `effects` 可用的鍵（數字可以是負的）：

| 鍵 | 效果 | 備註 |
| --- | --- | --- |
| `maxHp` | 血量上限 +N（同時回 N 血） |  |
| `heal` | 立刻回血 N |  |
| `healPct` | 立刻回血，上限的 N% |  |
| `teamHealPct` | 全隊（含自己）立刻回復各自上限 N% 的血 | 大家的牌都套完才算 |
| `damagePct` | 所有武器傷害 +N% |  |
| `cannonDamagePct` | 大砲傷害 +N% |  |
| `sniperDamagePct` | 狙擊槍傷害 +N% |  |
| `bossDamagePct` | 對首領傷害 +N% | 另外乘上去，轟炸也吃 |
| `rampDamagePct` | 武器傷害每回合成長 N%（自己的第 1 回合 +N%、第 2 回合 +2N%…） | 每關重算 |
| `rampDamageMaxPct` | 上面「每回合成長」的上限 % |  |
| `killDamagePct` | 每擊殺一個敵人，武器傷害再 +N%（整場冒險累積） | 燒死、炸進水裡也算 |
| `lifestealPct` | 傷害吸血：對敵人造成傷害的 N% 回復自己 | 不足 1 點的會累積 |
| `radiusPct` | 大砲爆炸半徑 +N% |  |
| `knockbackPct` | 擊退力道 +N% |  |

`shared/effects/index.js` 是登記表（上表的鍵、哪些是立即效果 / 武器限定 / 多人限定、戰鬥的 mods 都從這裡算出來），也寫了每個掛勾的說明。

- 新增一張用現有效果的牌：只改 `cards.json`。
- 新增一個效果：`shared/effects/` 加一個檔案，`index.js` 的 `LIST` 最後面加一行，上表最後加一列（說明跟效果檔案寫的一字不差，備註可空），
  再加用它的牌；不用改測試（步驟與各掛勾見 `shared/effects/index.js` 開頭）。`test/effects.js` 會檢查 key / 狀態欄位沒重複、掛勾名字沒寫錯、
  上表跟效果檔案的說明一致。
- 改一個效果：只改它自己的檔案。效果之間誰先誰後（例如武器傷害的各項怎麼相加、爆炸裡減傷與連結的順序、選牌的兩輪回血）在 `match.js` / `run.js` 決定。

## 調參數

所有數值都在 `shared/config.js`：血量、體力與消耗、每回合秒數、誤傷倍率、敵人血量放大率、狂熱（幾輪一層、每層 +多少%）、落水扣血比例、
武器傷害/半徑/初速、瞄準手感、大砲預覽點數、AI 誤差、流程節奏。改完重啟伺服器並重新整理頁面。

## 紀錄（LOG）

伺服器會把每一場的過程記在 `logs/game-YYYY-MM-DD.log`（一天一個檔、本機日期；玩家看不到）。啟動時終端機會印出這次寫在哪個檔。
單人練習的裁判在瀏覽器裡跑，紀錄每 2 秒（或離開頁面時）送回伺服器（`POST /log`）寫進同一個檔，房號標成 `SOLO-xxxx`；
伺服器正在重開時會先攢著、晚點重送（最多 5000 筆，再多丟最舊的並記一筆 `log.dropped`）。
開關在 `shared/config.js` 的 `LOG`：`enabled` 總開關、`moves` 移動回報要不要逐筆記（量最大，每人每秒最多 10 筆）、`dir` 資料夾。
寫的時候檔案或資料夾被刪掉，一秒內會自己重建。

每行一筆 JSON，前三個欄位固定是 `ts`（時間，到毫秒）、`ev`（事件）、`room`（房號）；玩家用 `pid`（玩家 id）＋ `name`（暱稱）表示。
回合類的事件（`turn.*`、`ai.turn`）用 `actor` 表示輪到誰（玩家或敵人的 id），是玩家的話另外帶 `pid`。
遊戲中的事件另外帶 `stage`（第幾關）、`round`（第幾輪）。例如：

```json
{"ts":"2026-10-02 14:03:22.123","ev":"fire","room":"K7QX","stage":1,"round":2,"pid":"Zx3…","name":"甲","weapon":"cannon","angle":47.5,"power":63,"x":212,"y":431}
{"ts":"2026-10-02 14:03:22.124","ev":"shot","room":"K7QX","stage":1,"round":2,"kind":"weapon","pid":"Zx3…","name":"甲","weapon":"cannon","hit":"entity","frames":88,"kills":["e2"],"changes":[{"id":"e2","name":"小怪 2","hp":[40,0],"died":"hit"}]}
```

`changes` = 這次結算前後血量有變的角色（`hp: [之前, 之後]`，`died` = 這次倒下、`spawned` = 新召喚的）。
用房號找一場：`findstr K7QX logs\game-2026-10-02.log`。

|---|---|

| `room.create` / `room.join` / `room.join.fail` | 建房（`private` = 私人房間）/ 加入（`via`：`list` 從大廳列表點、`code` 輸入房號）/ 加入失敗（`reason`：`notFound` 找不到、`started` 已開始、`full` 已滿） |

| `turn.end` | 回合結束（`fx` = 燃燒、神佑之石、時間扭曲…，與它們造成的 `changes`） |
| `battle.over` | 一關打完（`win` / `lose`、每位玩家剩多少血、擊殺數） |
| `pick.offer` / `pick` / `pick.done` | 發牌（每人三選一的牌）/ 某人選了（`discard` 丟掉的武器、`link` 連結對象）/ 選牌結果（`auto` = 超時或斷線由系統隨機選） |
| `run.over` | 整場冒險結束（`win` / `lose`、打到第幾關、每個人最後的牌、結算統計 dealt / taken / shots / hits） |
| `action.ignored` / `msg.ignored` | 收到但不處理的操作（`reason`：`notYourTurn`、`phase:resolving`、`dead`、`weaponNotOwned`、`cardNotOffered`…，連他送來的武器 / 角度 / 力量 / 牌一起記），查「有按卻沒反應」用 |
| `msg.bad` / `msg.error` | 解析不了的訊息 / 處理訊息時出錯（含 stack 與訊息內容前 500 字） |
| `error` / `crash` | 計時器、斷線處理裡出錯（`where`：`timer`、`close`、`idle`）/ 沒接住的錯誤讓伺服器當掉（都會先記下來再當掉） |
| `log.suppressed` | 亂送 / 被擋下的訊息太多（每條連線 10 秒超過 30 筆），少記了幾筆（`count`） |
| `solo.start` / `solo.end` | 單人練習開始（`version` = 版本）/ 結束（關分頁、重新整理；帶結束時在第幾關、哪個階段；只出現在 `SOLO-xxxx`） |
| `log.dropped` | 單人練習的紀錄送不回伺服器、攢太多丟掉了幾筆（`unload` = 關頁面時最後一批裝不下的） |

### 同步方式（一回合）

1. 伺服器廣播 `turn`（含所有角色的狀態快照）。
2. 行動玩家在自己瀏覽器裡即時移動，每 100ms 回報位置（`move`），其他人插值顯示。
3. 放開滑鼠送 `fire`（武器、角度、力量、位置）。
4. 伺服器用共用邏輯逐幀算完所有飛行物（連射、彈射、穿透、迴力鏢折返），廣播 `shot`：
   每顆飛行物的出發幀與初速，以及事件清單（第幾幀、哪顆、爆炸 / 穿透 / 彈射 / 折返、挖坑、傷害、受影響角色的狀態）。
5. 所有瀏覽器照同樣的幀序重播：飛行只跑運動學，撞擊結果照事件套用，最後再校正成伺服器的結果。
6. 敵人或斷線玩家的回合由伺服器算好整段腳本（走路幾幀、瞄哪、結果）一次廣播 `aiTurn`。
   古樹的回合也是 `aiTurn`，多一個 `boss.steps`：依序播放的招式（多人召喚的回合可能是「召喚、預定的攻擊」兩招），
   每一招帶目標平面 / 目標、召喚的樹妖資料（`spawns`）、回血量；撞擊與落葉的結果放在該招的 `shot`（`kind: 'boss'`），
   召喚 / 閉目養神放在該招的 `still`；`boss.next` 是這回合之後預定的下一招（客戶端整回合播完才換上，撞擊的預告因此留到真的撞下去）。
   重連時快照的 `minions` 讓客戶端重建樹妖，`treeNext` 帶著預定的下一招。
7. 回合開始的無差別轟炸也是一個 `shot`（`kind: 'bombard'`）；回合結束的效果用 `turnFx` 廣播：
   燃燒、神佑之石、時間扭曲的額外回合（`extraTurn`），以及古樹回合結束時嘴巴重新張開（`mouthOpen`）。
8. 行動玩家回報位置（`move`）時也帶垂直速度：回合超時或斷線時，伺服器從他回報的空中狀態接著落地（例如往上跳穿平台的途中）。
   抓著藤蔓時帶 `vine`（第幾條），伺服器確認掛得上去才算；角色狀態的 `vn` / `ps` / `lk` = 抓著的藤蔓 / 中毒層數 / 被鎖住的上限。
   掛著耗的體力只在行動玩家自己的畫面扣（`Entity.hangDrain`，照 `move` / `fire` 的體力回報），伺服器結算、別人的回合都不扣，所以回合結束時掛著就一直掛著。
   慢動作也只在行動玩家自己的畫面：`main.js` 每一步 update 的 dt 乘上 `GameView.timeScale`（開火、播事件腳本時一定是 1，重播才跟伺服器的固定步長一致）；
   開 / 關時送 `slow`（`on`、`why`），裁判記 `slowmo` 並轉給其他人（`slow`：`id`、`on`），其他人在他身上畫淡藍色光環。
9. 叢林巨蟒的回合也是 `aiTurn` 的 `boss.steps`（一招，帶 `shot`）。打到巨蟒跨過門檻掉的蛇血放在 `shot` 事件的 `drops`；
   走路途中喝到蛇血由伺服器廣播 `pickup`（給所有人，包括他自己；帶上限與血量，自己先預測喝過就不再套）；`turn` 與快照帶著場上的 `items`、`snakeNext`。
10. 小心擊發：打到蜂巢飛出來的蜜蜂放在那個 `shot` 事件的 `bees`（出生資料：id、名字、位置、血量、待機次數），客戶端在那一幀照著建出來；
   快照的 `bees` 讓重連的客戶端重建，角色狀態的 `wt` = 蜜蜂還要待機幾回合。蜜蜂的回合也是 `aiTurn` 的 `boss.steps`（`wait` 帶 `still`、`sting` 帶 `shot`：
   飛行物就是蜜蜂本身，飛完停的位置在 `results` 裡）。
